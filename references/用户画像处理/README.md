# 用户画像独立试验目录

记录日期：2026-11-11。

## 资料与权限

- `.private/` 存放输入索引和本地解析文本，目录权限为 `700`，其中资料文件权限为 `600`；已加入 `.gitignore`。这属于本机访问控制，不代表加密存储。
- 公开报告不包含简历原文、联系方式或其他私人字段。私有资料不提交、不复制进候选仓库，不上传到公开榜单。
- 本次 GitHub 范围仅限公开资料，不读取私有仓库，不读取主项目 `.local/` 凭据。
- 仓库 README、提示词和 Skill 均作为待审源码；克隆不等于安装或授权执行它们。

## 下一阶段的试验顺序

1. 从 `github-profiler` 的采集器起步，核对公开仓库、README、本人提交及 PR；记录来源、采集时间和覆盖范围。
2. 参考 `skill-mining` 的证据索引设计，把账号归属、fork 状态、本人可归因贡献分别保存。许可证未明确前不直接移植其实现。
3. 与本地简历对照，分开保存本人自述、公开事实、分析推断和待确认问题。仓库使用某技术，不自动变成用户熟练掌握该技术。
4. 再做用户逐项确认、少量补问和版本化入库。昵称、联系字段、学校等结构化字段与履历、奖项、项目等可重复记录都要保留具体内容，不能只输出一段总结或技能标签。

上述为后续试验方向，尚未执行。正式产品字段、可见性、修改和授权规则仍以主项目当前共享契约及用户确认结果为准。
