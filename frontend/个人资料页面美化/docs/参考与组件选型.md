## 2. 两个 Skill 的职责

| Skill | 本轮使用方式 |
| --- | --- |
| shadcnuikit | 阅读完整指引，使用 MCP 的 plan_page、search_catalog、get_item_code 查找布局与滚流部件 |
| ui-ux-pro-max | 阅读完整指引，并查询动态内容的可读性与 reduced motion；使用结果约束动效、触摸与键盘体验 |

现有 Signalry 基准已明确，不另生成或持久化新的主题方案。第一次 UX 查询 `pause moving content` 没有直接命中动效规则，未采用其泛化结果；重试 `reduced motion` 后命中 Reduced Motion 和 Excessive Motion。

AffectUI 是本项目选定的另一组件来源，本轮通过其 MCP 查询动效并阅读组件说明；这里不将它误写成已安装的同名 Skill。

## 3. 组件复用候选

| 功能 | 来源 | 状态与适配方式 |
| --- | --- | --- |
| 主题、字体、按钮、卡片、弹层 | 本地 Signalry / 首页 | 已查基准；后续复制必要文件到本目录，不改参考文件 |
| 慢速循环 | Shadcn UI Kit hero14 / 首页 KitMarquee | 已检索并读取 hero14 源码；优先研究首页已有暂停与循环实现，转为本页发散轨迹 |
| 卡片切换 | AffectUI blur-crossfade | 已读取说明；使用 id 切换、短暂柔焦和 morph=none，避免浮动卡片持续改变尺寸 |
| 浅色光场 | AffectUI gradient-floor | MCP 已匹配；首页已有适配副本，沿用 Signalry 变量 |
| 照片指针响应 | AffectUI tilt-card | MCP 已匹配；首页已有适配副本，控制倾斜与反光幅度 |
| 名称 / 短标题入场 | AffectUI text-reveal | MCP 已匹配；首页已有适配副本，保持正文稳定 |
| 淡网格 | 首页 GridBackground，来源 AffectUI | 已核对 Hero 使用与文件存在，后续按本页降低密度 |
| 下方想法和活动 | Signalry Features / Kit Card、Tabs、Dialog | 使用已有宽窄关系与控件组合；具体区块源码在实施对应阶段进一步核对 |

hero14 提供循环机制，原始用途是商品图片，不是现成的“个人资料发散场”。本页需要在复用基础上实现用户指定的轨迹布局，不能声称原库已经具有完全相同效果。

Kit 当前返回项使用 radix-luma；首页使用 radix-vega。后续只在业务区块 className/props 中补足显式间距，不覆盖基础 components/ui。

组件可优先复用本地已授权快照。若需要新增下载，遵循用户指定 CollectUI registry；不在文档、源码和日志中保存带凭据的安装命令。

## 4. 后端资料与页面内容对应

已读取 [FieldCatalog.php](../../../backend/protected/modules/matcher-user-profile/domain/FieldCatalog.php)、[资料读取控制器](../../../backend/protected/modules/matcher-user-profile/controllers/ApiController.php)、[展示条目选择](../../../backend/protected/modules/matcher-user-profile/application/ProfilePresentationService.php)，并检查想法服务中的内容与关系字段。

| 页面内容 | 已有来源 / 含义 | 展示注意 |
| --- | --- | --- |
| 姓名与头像 | nickname、avatar_ref 身份字段 | 稳定展示；照片效果需适应头像素材质量 |
| 简介 | headline、bio | 首屏只放简短内容，长文进入静态详情 |
| 能力 | skill、role、direction | 显示本人确认的内容，不制作虚构能力评分 |
| 个性与兴趣 | personality、mbti、interest | MBTI 为本人自述；不根据外观或行为推断 |
| 协作期待 | seeking、collaboration_preference、communication_preference | 使用短句；不把长期期待替代本次活动目标 |
| 项目与成果 | project、award、portfolio_link | 来自可见条目；没有数据不补造奖项或链接 |
| 本次活动信息 | event_goal、event_role、event_seeking 等 event 范围字段 | 明确所属 Space，不能跨活动拼接 |
| 自己的想法 | matcher-ideas 的 title、summary 与活动发布关系 | 区分作者、参与关系、想法状态与活动发布状态 |
| 活动经历 | 只读 activities 关系及活动信息 | 逐对象授权；当前/历史分类需另核对可靠时间与关系语义 |
| 联系方式 | contact_* 独立字段 | 必须遵循独立读取与条目可见性 |

原版 [about.php](../../../backend/protected/humhub/modules/user/views/profile/about.php) 使用字段分类和标签页呈现资料。本轮仅据此确认原资料展示入口；本页视觉按用户指定的新构图设计。
