# V3 实现与验证

2026-11-12。独立的 React / Next.js 个人主页预览，全部改动在个人资料页面美化目录。

## 访客路径

概览 → AI 合作推荐 → 资料详情列表 → 想法与项目 → 参与活动 → 好友申请。

顶部保留照片和错峰生长的消息条。信息架构由原先七个平铺板块调整为一次自然的浏览过程，先知道对方是谁，再判断合作可能，之后按需展开事实资料，最后看作品与活动。导航对应概览、AI 推荐、资料详情、想法与项目。

详情使用四个可独立展开的分组。默认展示能力与协作、教育与经历；基本信息和活动投入按需展开。左侧字段名、右侧可读摘要，技能集中排列，同一字段的多个条目不散落到其他类型之间。手机仍保持字段和值的明确对齐。

想法与项目使用全部/想法/项目三个 Tab。想法说明本人在其中的关系，项目说明实际贡献与成果。活动关系放在作品区之后；历史活动继续显式标注为布局预览。

## 原始组件来源与适配

先通过 shadcnuikit Skill 和 MCP 查找并读取源码，再在本目录组合。沿用此前 ui-ux-pro-max 的布局和交互检查建议，视觉以用户指定的 Signalry 为准。

| 部件 | 来源 | 本地适配 |
| --- | --- | --- |
| 分组资料 | Shadcn UI Kit accordion7 | 保留图标、标题、副标题、展开结构，加入只读资料行 |
| 字段与内容行 | Shadcn UI Kit form-layout3 | 使用标签/内容网格，替换表单输入为资料摘要 |
| 想法与项目卡 | Shadcn UI Kit blog-card1 | 保留图文卡、作者和操作结构，内容换成想法关系与项目贡献 |
| 页面底部邀请 | Shadcn UI Kit cta11 | 保留标题/照片与右侧两个操作卡结构 |
| 好友申请 | AffectUI email-draft-clean | 保留编辑、语气、回执和高度过渡；固定收件人，去掉邮件附件、地址与发送行为 |
| AI 资料依据 | AffectUI cited-answer-clean | 延续 V2 的中文引用和原资料弹层 |

新增 Accordion、Tabs、Avatar 与 Signalry 原文件逐字节一致，见 [源码核对](v3-component-check.json)。没有改动基础组件；主题和响应式适配放在业务组件及 app/profile.css。原始 vendor、首页、后端均保持只读。

这次修正了手机卡片按钮占满一行而挤压作者的情况。资料摘要在窄屏按可用宽度换行，作者与按钮并排保持可读。申请编辑器在 320px 下独立适配正文、语气与底部按钮。

## 共享申请草稿

所有申请入口共用一个父级草稿状态。顶部编辑后可在底部继续，不会生成第二份不同草稿。支持自然、简短、具体三种预写语气，用户可手动修改，正文上限 300 字。

- 空白草稿不能保存。
- 支持放下草稿、恢复草稿、保存后继续编辑。
- Ctrl/Cmd + Enter 保存本页草稿；编辑正文时 Esc 先退出编辑，再按 Esc 关闭弹窗。
- 关闭后焦点返回原入口。
- 模拟观看者或可见资料集合变化时清除旧草稿；照片、长文案等纯视觉状态不清空同一上下文的草稿。

这里只模拟起草和保存，明确标注预写示例。没有调用模型、发送请求、创建好友关系或永久保存。刷新页面重置。

## 资料与隐私

[字段检查](v3-fixture-check.json)记录 29 条可见资料：19 条 global、10 条 event。详情列表 27 条，项目记录 2 条，概览池 25 条。字段名和范围沿用 backend FieldCatalog。

两行仅好友可见样式为单独的抽象占位，只有通用分类标签与空形状；没有受限文本藏在 CSS blur 下。工作经历和个性细节的原示例值已从运行时资料中移除，不参与概览、AI 推荐或好友申请。private 不占位、不渲染。联系方式仍为独立授权。

所有人物和内容都是演示。前端场景切换不是服务端权限系统；真实接入须使用后端对合法入口、当前用户、活动范围的授权投影。AI 推荐只能使用 authenticated 输入，即使观看者是好友，也不能将 friends 字段直接作为推荐输入。本次没有运行后端接口或 PHP 验证器。

## 验证记录

本轮浏览器检查全部通过。61 秒真实动效采样覆盖 25 条消息、四个阶段和 306 种裁切状态；无运行时错误、HTTP 错误或外部网络请求。

实际结果以 [V3 浏览器记录](v3-verification.json)、[320px 完整消息池检查](v3-compact-check.json)为准，V2 的测试不用于证明新版。

检查覆盖七种宽度（1440 / 1100 / 1024 / 901 / 768 / 390 / 320）、阅读顺序、页面横向溢出、资料行与项目卡内部溢出、消息碰撞与裁切、重复 DOM ID。

互动检查覆盖折叠列表键盘操作、条目弹层、引用依据、三种观看者、想法/项目 Tab、收藏、当前/历史活动、草稿语气与编辑、上下入口续写、放下/恢复、300 字上限、空白禁用、键盘保存、Esc 和手机导航。受限原值同时检查 DOM、实际交付 HTML 和 JavaScript；保存草稿后仍保持锁定样式。

少量资料、长姓名/长条目、缺失照片在 1440 / 390 / 320 三种宽度分别检查。用 Chrome CDP 检查真实 glyph 渲染的 Bricolage Grotesque、Inter 和中文 PingFang SC。真实运行的消息流覆盖生长、停留、收回、隐藏四阶段，另外检查悬停、焦点、弹窗、离屏暂停及系统减少动态效果。

生产构建、类型检查和 ESLint 的结果见 [构建与目视检查记录](v3-release-check.json)；Next.js 16.4.0 仍报告依赖安全升级提醒，本次没有升级。预览仅绑定 127.0.0.1，不用于公开部署。
