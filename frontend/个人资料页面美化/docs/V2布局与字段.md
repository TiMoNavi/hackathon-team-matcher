## 这次调整

1. Hero 左侧肖像，右侧简短身份。八条错峰资料消息从左向右展开，停留阅读，向左收回，换条目后再展开；内容池来自结构化字段。
2. AI 合作参考面向观看者：结合模拟观看者背景解释能力互补、共同方向、时间约束，并给出可点击依据和建议开场白。始终标注预写演示，不调用模型，不编造匹配百分比。
3. 完整资料分为能力、项目与经历、性格与协作、本次投入、想法、参与活动。字段都可静态阅读，不要求等动效才能获得信息。
4. 继承 Signalry 的字体、主题、1248px 容器、宽窄比例与 24px 卡片；沿用 shadcnuikit、ui-ux-pro-max。时间线引用 Kit changelog2，AI 依据交互复用 AffectUI cited-answer-clean。

## 后端映射

来源为 backend/protected/modules/matcher-user-profile/domain/FieldCatalog.php，以及资料概览/关系摘要契约。完整目录见 backend-fields.json。

- 独立身份 nickname、avatar_ref；27 类全局字段、10 类活动字段，普通字段均可缺省，重复字段不限定为六项。
- 首屏短条是可见条目的摘要，不是另建一套资料字段。下方保留完整内容。
- 全局能力/经历：direction、skill（self_level 为本人自评）、role、interest、project、education、work_experience、award。
- 全局协作：city、timezone、personality、language、seeking、collaboration_preference、communication_preference。
- 本次活动：event_goal、event_seeking、event_role、event_contribution、event_time_commitment、event_availability、event_collaboration_mode、event_presence、event_contact_preference、event_constraint。
- 联系方式单独授权读取；原型不展示假联系方式。未填 bio/MBTI/年龄/真实姓名等字段不补编。
- 当前 API 的 idea_groups/activities 关系仅覆盖服务器确认的当前活动；历史活动放在明确的历史布局预览中，不冒充现有跨活动能力。
- AI 主页总结未确认存在正式端点。本地预写示例只引用当前演示可见条目；缺资料/未选择观看者背景时不输出个性化判断。

## 动效约束

使用 clip-path 揭示消息，文本不缩放。每条独立生长、停留、收回；同一轨道始终只显示一条。全部条目可从正文阅读。暂停按钮、悬停、键盘聚焦、弹窗、离屏与后台页面均暂停。减少动态效果时显示完整静态条目，仍可手动换组。
