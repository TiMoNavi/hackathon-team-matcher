# V1 独立个人主页

日期：2026-11-12。范围：个人主页视觉原型，未接入后端。

## 页面与卡片排版

首屏沿用 Signalry 的 1248px 容器、浅色主题、紫色主操作、青柠强调和字体职责。左侧为大幅照片与固定身份信息，右侧为自述标题与资料场。

为落实用户特别强调的资料卡排版，本版采用受约束的错落布局：

- 六张卡分为三条轨道，轨道上两张卡采用不同宽度比例；三轨的起点、倾角与卡高不同。
- 卡位分别承载技能、生活坐标、项目、相处方式、合作期待与兴趣，尺寸服务内容，不按字符数随机生成大小。
- 每轨通过 Web Animations API 在约 18px 的范围内缓慢横向漂移，周期分别为 18、22、20 秒；固定轨道间距，避免互相挤压。暂停时保存并锁定 currentTime，恢复时从原位置继续。
- 每 9 秒错峰替换一个卡位，完整更换六个卡位需 54 秒。替换用 AffectUI BlurCrossfade，固定卡位尺寸并关闭尺寸 morph。
- 悬停整个资料场或键盘聚焦其中任一卡片时暂停漂移和自动更换；打开详情、窗口后台、资料场离开视口也暂停。
- 全局动效开关与系统减少动态效果生效；照片轻视差与主要文字区域分开。
- 右下角「换一组」允许主动更换；资料少时减少卡片，不填充重复或虚构条目。

桌面初版截图发现卡片字小，第二轮已放大标签、标题和正文，增加卡高与轨道间距。手机使用稳定的精选卡片布局，保留完整资料入口；320px 下较窄的中间卡片进一步改为单列。

这是按用户要求组合的发散资料场。循环与暂停思路参考首页的 Kit hero14 适配，但当前采用有界漂移与原位替换，不把整个资料条无限滚出屏幕。

## 组件与素材

- Signalry / 首页：主题、Button、Dialog、Card、Badge、字体副本、运动偏好上下文。复制时指纹见 source-manifest.json，components/ui 未进行定制。
- Shadcn UI Kit hero14：已在规划阶段读取源代码，其轨道测量与暂停方式作为参考；业务资料场代码位于 components/facts-field.tsx。
- AffectUI：首页中的 tilt-card、blur-crossfade、gradient-floor、grid-background 适配副本，统一使用 Signalry 主题。
- 想法卡的地图与灵感纸片为本地 CSS/SVG 展示图形，配合 Lucide 图标，不引入第三方组件库。
- 肖像下载后存于 public/images，源地址与用途记录于 SOURCES.json；首页演示头像副本用于页尾。
- 英文标题使用本地 Bricolage Grotesque，正文 Inter；中文字体实际结果见 verification.json 的 platformFonts。

## 验证方法

自动化脚本 scripts/verify.mjs 在本机 Chromium 中检查：

1. 1440、1100、1024、901、768、390、320px 下的页面横向溢出、卡片几何重叠与内容裁切。
2. 资料弹层、Esc、焦点恢复、手动换组、收藏、想法详情、活动筛选与详情、本地开场白。
3. 稀疏、长文案、缺失照片在 1440、390、320px 下的布局。
4. 手机导航、详情布局，以及系统减少动态效果。
5. CDP 平台实际渲染字体；区分中文字体和英文 web font。
6. 连续 56 秒的轨道与卡片替换采样，再检查悬停、键盘聚焦和离屏暂停。
7. 页面运行错误与外部网络请求。

最终通过结果保存在 verification.json，桌面和手机截图在 screenshots/。首轮浏览器工具启动失败后，改用本机已有的 Playwright 与 Chromium headless shell；浏览器临时文件限定在本目录 .cache/tmp。

类型检查、lint、生产构建使用本目录独立依赖。Next.js 工具报告既有版本的安全升级提示，首轮构建因此退出；重试后构建成功，安全提示仍记录为待处理，不代表已修复漏洞。
