# V3 访客阅读路径

2026-11-12。保持独立，所有改动只在个人资料页面美化。

顺序改为：概览 → AI 合作推荐 → 资料详情列表 → 想法与项目（含活动关系）→ 好友申请。

- 概览保留用户认可的肖像与生长资料流，集中回答身份、能力、方向、本次需求。
- AI 参考在概览之后，帮助观看者判断共同话题与合作方式；与资料事实分开。
- 详情使用 Shadcn UI Kit accordion7 的图标/副标题折叠分组，结合 form-layout3 的左标签/右内容行。当前观看者可见范围由后端投影决定，原型只消费演示的可见条目。
- 工作背景和个性细节使用独立的隐私占位示例。占位只有通用分类与形状，没有受限原文，不能通过取消 CSS 模糊读取。private 不呈现；联系方式另行授权，好友身份不等于联系方式授权。
- 顶部与底部都进入同一个好友申请编辑器；AffectUI email-draft-clean 适配为申请草稿，保留语气切换、编辑、人工确认。仅预写示例与本地保存，不发请求、不建立好友关系、不假装打开隐私条目。
- 底部邀请区组合 Shadcn UI Kit cta11，全部继续使用 Signalry 字体、主题和尺寸。

V2 源码已归档 docs/revisions/v2-source.tar.gz。V3 的最终截图和验证记录另存，V2 记录不作为新版验收。
