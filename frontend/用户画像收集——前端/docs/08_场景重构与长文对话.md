# 场景重构与长文对话

2026-11-12，第二版。入口为 http://127.0.0.1:4199/guide 。本版对应用户逐页提出的修改要求，替代第一版的居中短表单编排。十个业务阶段保持原编号，寻找与推荐结果属于同一段发现体验。

## 页面整体如何展开

保留 Signalry 的语义主题、导航尺度、Inter 正文和 Bricolage Grotesque 英文展示字体。白天是白色画布、浅网格与渐变色光，夜间改为深色画布。边框只用于帮助辨认阅读区域、输入和操作；处理中没有包住整个 AI 过程的卡片。

页面只有一个持续存在的云朵角色。它从开场上方移动到处理区域，再到资料左侧；对话时缩入当前助手消息的头像，最终资料与推荐时停在右下角。白天用主题紫色，夜间使用 AffectUI 原版橙色 Glow Cloud。角色在长对话中随消息滚动，离开消息视窗后被裁切，不飘到导航栏上。

标题以逐字浮现进入，处理阶段使用汇聚光束、思考状态和任务轨迹。减少动态时保留静态角色与全部功能，停止持续动画。所有演示处理可以立即跳过。

## 每一页应该有什么

| 阶段 | 画面与内容 | 主要交互 |
| --- | --- | --- |
| 1 资料入口 | 上方角色，下方等宽等高的简历与 GitHub 入口；文字与网址为可展开补充 | 明确的「GitHub 登录并导入」按钮；顶部「暂时跳过」和底部「什么都不填，先去看看」；手动填写与示例体验单独列出 |
| 2 处理资料 | 大范围、无外框的 AI 处理场景；角色位于资料汇聚中心，轨迹与阶段说明占据主视觉 | 跳过演示动画；失败后重试、手动继续或主动使用示例 |
| 3 初步核对 | 左侧角色及简短说明；右侧宽阅读区，以完整段落展示介绍、经历和项目 | 点击具体段落的「修改」再出现多行编辑器；保留换行与长内容，不裁成一句话；没有资料时仅称呼必填 |
| 4 偏好对话 | 正常对话消息区；先有思考反馈，再出现助手提问；角色融入消息头像 | 底部多行输入，Plan 模式展示三项聊天范围；建议只填入输入框，不自动发送；每题可跳过 |
| 5 确认画像 | 角色回到左侧；右侧宽、可滚动、半透明边界的完整资料 | 阅读为默认状态；切换「编辑资料与范围」；逐条可见性、增删条目，以及本人／登录用户／好友预览 |
| 6 讲讲想法 | 回到聊天布局；角色再次进入助手头像，保留多个已发送的想法 | 支持长篇描述、想发起或想加入的方向；未发送的输入也保存；每个想法独立保留 |
| 7 完善想法 | 助手继续提问和思考，随后在消息流里返回一份完整计划 | 计划包含目标、人群、第一步、需要的帮助和待讨论问题；支持直接修改长段落，或继续对话补充 |
| 8 最后确认 | 角色停在右下角；主体为整齐的资料文档，包含「关于你／想法与计划／本次活动」目录 | 各部分可长篇阅读、滚动核对、返回修改；活动答案与发现范围分别设置；保存不会自动发邀请 |
| 9 本活动寻找 | 角色保持右下角，开放式 AI 寻找过程 | 只在选定活动内进行演示；切活动或离开会使旧任务失效 |
| 10 推荐结果 | 左侧一摞候选卡，右侧宽详情；手机在卡片列表和详情之间切换 | 「是的，想认识」「不太合适」、多选想认识名单；好友申请必须再确认收件人和附言；关注想法、申请讨论独立处理 |

## 长内容与输入

阅读区域采用完整段落与自然换行，不用几行文本框代表整份资料。长介绍、项目经历和计划都有独立滚动空间，页面不会因增加文字而横向撑开。点击修改后，多行编辑器随内容增长，仍允许继续滚动编辑。粘贴文字、对话输入的上限为 20,000 字符；这个上限不是预览截断。

对话输入在可见区域底部，长消息在上方滚动。Enter 发送，Shift + Enter 换行；中文输入法选词时不会误发送。Plan 模式只展示本轮需要聊的范围和进度，不把大选择题放在画面中央。计划生成后继续编辑不会让整份计划消失。

手机将左右阅读布局纵向排列，保留大段内容和所有修改入口。推荐页用「返回卡片／上一张／下一张」切换，避免在窄屏同时塞入两个难读的栏。

## 已接入的前端行为

- 同一浏览器自动保存与刷新恢复，兼容已有草稿；测试不清空日常浏览器的进度。
- 跳过全部资料可直接浏览示例候选，不生成虚构画像，不把引导标为完成。
- 多想法、独立计划、活动答案隔离、可见性预览、失败重试与旧任务取消仍有效。
- 好友申请先形成想认识名单，再明确确认；本机只记录待接受状态，不假定已经成为好友。
- 保存失败留在编辑页；损坏的草稿不被自动覆盖。

## 真实服务接入边界

GitHub 按钮已存在并可操作。配置 NEXT_PUBLIC_GITHUB_AUTH_URL 后可跳往现有授权入口；当前预览没有配置真实 OAuth，点击会明确说明未接通，并允许返回或主动使用示例。未增加自行收集密码或 token 的表单。

文件只保存名称与来源信息，不上传或解析文件；粘贴文字完整保存在本机。AI 思考、计划整理、推荐与社交结果仍是标明演示的前端行为，没有后台模型调用或真实好友请求。计划整理不杜撰用户经历，不确定的内容保留为待讨论事项。真实接入继续按 [画像需求](../../../docs/用户画像收集/01_用户画像填写需求.md) 及项目共享契约实施，不另建业务规则。

本轮未部署，也未改变此前已记录的依赖审计状态。现有审计记录见 [组件扩展说明](06_背景装饰边框与卡片.md)。
