# 用户画像引导采集流程

原设计日期：2026-11-11。本文档组把用户提供的零散设想整理为可供前端设计、实现和交互验证使用的页面说明，属于衍生设计。2026-11-12 已按用户指定迁入当前前端目录，并先后新增组件参考库与完整十阶段交互原型，运行方式见 [项目入口](../README.md)。

## 页面方向

做一个像游戏开场一样逐步展开的 AI 引导页面。以白色为主，支持夜间模式；背景是缓慢流动的浅色渐变。2026-11-12 最新逐页要求采用场景切换：开场居中、处理过程展开、长资料旁放置角色、对话时角色融入助手头像、最终资料和推荐时停在右下角。当前具体页面编排以第四版修订与第二版场景说明共同为准。

体验以少输入、多确认、可跳过、可返回为原则。AI 从用户提供的资料中整理信息，用户核对、回答少量问题并决定资料的展示范围，再进入想法完善和当前活动内的发现。动效负责解释状态变化，不增加等待时间。

## 本次范围

- 明确页面区域、十阶段内容、文案、主要动作和分支。
- 明确白天与夜间模式、AI 形象、渐变背景、AffectUI 动效和手机适配。
- 给出后续交互原型应覆盖的状态和验收场景。
- 已实现完整十阶段前端交互原型，入口 /guide；AI、资料解析、推荐和社交仍为演示，尚未连接正式服务。

首页演示与登录是进入引导前的入口；登录后的十步沿用现行产品定义。原始材料中的十一点设想和八屏草案用于理解体验，不再作为第二套步骤编号。
