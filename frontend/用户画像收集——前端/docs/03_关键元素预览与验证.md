# 关键元素预览 · 实现与验证

日期：2026-11-12。用户本轮指定本目录为前端后续产出位置，并要求主要调用 AffectUI，先生成一页选出的关键元素。实际入口与运行命令见 [README](../README.md)。

## 实际交付

一页 Next.js / React 预览，四个可切换场景为认识你、整理中、画像卡、聊想法。它验证同一页面内的形象、文案、输入和动效组合，没有将四个预览标签当成正式十步编号。

原有三份说明从 docs/用户画像收集/前端引导流程迁入本目录 docs/，重新计算了相对链接，并更新前端总入口、画像文档入口和专项任务入口。新增 AGENTS.md 记录用户指定的固定目录。

## 组件来源与适配

| AffectUI 组件 | 本页用途 | 适配方式 |
| --- | --- | --- |
| Voice Orb | AI 呼吸、思考环与输出波纹 | 真实组件状态切换；颜色使用主题变量；文字状态在外围展示，不呈现语音入口 |
| Thinking Loader Clean | 当前模拟处理阶段 | 由本页演示状态控制 phase / done |
| Thinking State Clean | 展开模拟资料与步骤 | 明确标演示；组件播放结束不触发画像保存或业务完成 |
| AI Answer Clean | 对话回复与复制、停止等反馈 | 本页预设文字逐段提供；保留原组件结构，外围修正内容区留白，避免末行裁切 |
| Text Area Clean | 一句话介绍和多行对话输入 | 通过 props 控制输入、标签、快捷键与长度；本轮通过 AffectUI MCP 取得源码 |
| Dropzone Clean | 展开后的文件选择与进度反馈 | 只接本地模拟回调，不读取正文或发起网络上传 |
| Segmented Control Clean | 四个预览场景切换 | 保留滑动指示与键盘交互；外围适配 320px 等宽布局 |
| Button Clean | 主次按钮、快捷建议和主题操作 | 通过主题变量与 className 对齐 Signalry 的品牌、尺寸、焦点和圆角 |
| Text Reveal | 下方介绍区的一句文字入场 | 只用于短句，关键问题与操作说明立即出现 |

九份源文件保持字节不变，SHA-256 见 [组件清单](component-sources.json)。前八份来自现有 CollectUI 库快照，Text Area Clean 通过已连接的 AffectUI 工具获取；没有修改 vendor 或原版预览，也没有把凭据写入文件。

基础排版继续使用 Signalry 的 1248px 外容器、顶部 16px 间距、16px 导航圆角、56px 背景网格、32/36px 表单标题与 24px 面板圆角。页面适配围绕用户要求的纵向引导舞台进行，下方介绍区沿用宽窄卡片关系。

明亮主题变量来自原版；夜间主题在本目录补齐。AffectUI 的主题适配集中在 [affectui-theme.css](../app/affectui-theme.css)，不在原组件内部换样式。

## 字体核对

英文字体文件取自已运行 Signalry 原版的字体缓存，复制后从本页本地加载，无需运行时外连字体站点。来源和哈希见 [字体记录](font-sources.json)。

本机 Chromium 通过 CDP 实际渲染字体接口检查：英文品牌字样使用 Bricolage Grotesque，英文正文使用 Inter；中文标题使用 PingFang SC Semibold，中文正文使用 PingFang SC Regular。中文仍为当前平台字形，没有将英文字体加载成功当作中文品牌字体已经确定。其他操作系统的中文字形尚未验证。

## 浏览器检查

可重复运行 [verify.mjs](../scripts/verify.mjs)。结果保存为 [verification.json](../artifacts/verification.json)，其中 verifiedAt 为 UTC 时间戳；本次操作对应上海时间 2026-11-12。

验证范围包括：

- 1440、768、390、320px 视口的浅色布局和夜间对话布局，检查文档横向溢出与关键操作裁切。
- 快捷建议填入输入、模拟失败与重试、昵称与介绍修改、技能删除和示例可见性调整。
- 发送想法、预设回复、中文输入法 Enter 不误发，检查回复末行不被操作栏遮挡。
- 主题刷新恢复；个人输入不写入持久存储。
- 手动与系统减少动态设置下，替换为静态形象并保留全部操作。
- 选择合成测试文件后有本地反馈，期间没有上传请求。
- 切换场景取消旧计时任务，不让过时结果跳转当前页面。
- 页面脚本错误、失败请求和键盘焦点检查。

初次检查发现 320px 的最后一个标签被裁切，已通过外围网格适配修正。截图复查发现回复区外围留白影响原组件高度测量，已将留白移到被测量的内容层，保持基础组件不变。

原浏览器连接工具因本机 Chrome 启动异常失败，随后改用 Playwright 自带 Chromium 完成真实页面检查。截图包含原版 Signalry 的桌面与手机对照；原版只读访问，不修改文件。

## 当前边界

- 没有真实 AI、OAuth、服务器资料保存、活动检索或好友操作。
- 画像是虚构示例，预设回复不基于模型理解，不能作为画像能力验收。
- 文件格式与 10 MB 限制仅用于本页演示，不覆盖后端上传契约。
- 本页是宽度适配和交互验证，尚未在物理手机、系统软键盘和不同操作系统字体环境下验收。
- 完整十步、各活动权限、资料逐条确认与真实服务状态需要在后续页面中继续接入。
