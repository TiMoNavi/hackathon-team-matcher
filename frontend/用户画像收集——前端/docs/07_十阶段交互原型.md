## 怎样体验

打开 /guide，点击「先用示例体验」，可以从资料整理一路走到活动内示例结果。也可以直接填写自己的称呼，不使用任何示例资料。所有处理动画都能立即跳过；偏好选择需要点击继续，不会点一下就跳题。

右上角可以切换夜间模式、保存退出。在体验设置里，可以选择跟随系统、减少动态效果、更换示例活动，以及试验失败或空结果场景。刷新会恢复同一步骤及本机已保存的内容。重新体验需要在设置里明确选择清空本机草稿。

## 页面编排

页面以白色为主，背景是原版 Grid Background 与 Gradient Floor 的网格、流动色光。导航沿用 Signalry 的 1248px 容器，主体是上方 AI 角色、中间引导文字、下方阶段内容的纵向舞台。标题取原版表单的 32/36px 层级，介绍宽度 640px，普通舞台 880px；画像、想法对话与最终预览使用 1120px 的宽舞台、20px 间隔及约 64/36 的宽窄列组合。

云朵角色会眨眼、跟随指针，整理时进入思考状态。背景保持在后方，输入与长文字本身保持稳定。切换步骤用 Blur Crossfade，偏好点选用 Kit AnimatedBackground，画像预览用 Tilt Card。夜间模式继承 Signalry 的语义主题；减少动态时替换为静态角色和背景，停用光流与动效。

手机将画像拆为「编辑资料／预览名片」，想法完善拆为「对话／方案」。结果先展示概览，用户再展开详情；输入与选择在切换视图后保留。

## 十个阶段的实际内容

| 阶段 | 页面呈现 | 用户动作与规则 |
| --- | --- | --- |
| 1 提供资料 | 玻璃文件夹、GitHub 示例入口、可展开的文字与网址输入 | 选择本地文件或输入资料；也可不提供资料，直接进入第 3 步 |
| 2 整理信息 | 资料汇聚光束、思考文字、三段处理轨迹 | 立即跳过动画；解析不可用时显示原因，可手动继续或主动使用示例 |
| 3 初步核对 | 昵称、介绍、角色与技能标签 | 只要求称呼，其他内容自愿补充；导入条目先核对 |
| 4 补充偏好 | 三张依次出现的问题、动态选项底板、自定义回答 | 固定三题，每题都可跳过；点击选项后需主动继续 |
| 5 确认画像 | 逐条编辑、逐条可见性与动态名片预览 | 可添加或删除条目；切换本人、其他登录用户、好友视角，再确认保存 |
| 6 讲讲想法 | 想法输入、加入项目意愿、多个独立草稿卡 | 至少保留一个具体方向；未发送的输入也会保存 |
| 7 完善想法 | 轻量对话、快捷回答、可编辑方案、整理进度 | 每个想法独立回答目标人群、第一步、需要的帮助；可以少答，未知内容留空 |
| 8 最后确认 | 画像与想法预览、范围设置、活动与本次投入 | 可返回修改；发现开关默认关闭；活动答案分别保存 |
| 9 本活动寻找 | 活动、画像、想法汇聚与寻找轨迹 | 只使用当前活动示例；切活动、离开或取消后，旧任务不再生效 |
| 10 遇见同伴 | 人物或想法卡、详情、上一张／下一张 | 好友申请先确认；关注想法、申请讨论分别记录；可保存并完成 |

章节组织仍为「认识你 → 了解你的偏好 → 让想法成形 → 遇见同频者」。没有活动时保留画像与想法，不回退到全站找人；零结果必须由用户主动选择普通浏览。

## 状态与数据边界

- 普通已确认字段默认对所有登录用户可见，可逐条改为仅好友或仅自己。原始资料、未确认草稿和初始想法不自动发布；登录邮箱不自动变成联系方式。
- 本地状态以 team-matcher-onboarding-v1 保存在当前浏览器。自动保存有 250ms 防抖，关键确认和保存退出会立即尝试写入。
- 保存失败明确提示并保留当前编辑，不跳转成保存成功。损坏或不兼容的旧记录不会被自动覆盖，需要明确清空重开。
- 状态校验涵盖题号、字段、消息、想法版本、活动信息与任务结构。修改已完成画像或想法会撤销最终确认状态。
- 演示任务以任务 ID、想法版本和活动 ID 校验有效性。编辑、取消、离开和切换活动后，过时结果不能覆盖新输入。
- 多个想法保留各自的对话与方案；活动的贡献、时间和发现设置也分别保存。
- 好友申请仅记录为待接受；不等于已经成为好友，也不自动开放私人内容。想法关注与讨论申请独立记录。

- 上述流程、分支和视图测试未记录页面或控制台错误。原 48 组组件参考页也完成了入口与组件加载检查。

## 原型边界与后续接入

这是完整流程的前端体验，真实登录、文件解析、GitHub OAuth、AI、推荐和社交服务尚未接入。页面始终标注演示，不把定时动画当作后台任务。文件只保留名称及来源类别，不上传、不读取文件内容；粘贴文字作本地原文摘录。示例人物资料仅在用户主动使用示例入口时加入。

AI 思考视觉展示任务阶段，不展示虚构的内部推理、置信度或匹配分。想法草稿只整理用户已提供的内容，不凭空生成经历、成果或技术方案。后续真实服务接入需要替换演示适配层，并按现有后端共享契约校验权限与活动边界。

本轮未升级既有依赖；此前记录的依赖审计问题仍见 [组件扩展说明](06_背景装饰边框与卡片.md) 与 [审计记录](../artifacts/dependency-audit.json)。当前仅供本机预览，未部署。
