# 更多可用组件与阶段对应

2026-11-12。用户反馈前六组可以参考，但数量和覆盖仍不够。本轮新增 20 组可运行参考，对照页共 26 组；包括 8 组优先候选。它们都是选型材料，尚未成为正式页面定稿。

## 预览入口

http://127.0.0.1:4199/references

可按 AI 形象、资料与思考、少填与对话、卡片与同伴、转场与背景、完整流程筛选，也可搜索组件英文名、中文名或阶段。选择会更新地址中的 scene 参数，便于直接回到同一组件。一次仅渲染选中的场景。

## 优先看的组合

1. 资料进入 AI：Integration Beam / Integration Flow。前者有悬停和点击暂停，后者是弧形轮转与中心充能的自动场景。可用于理解多种材料如何进入画像。
2. 思考与展开：Agent Trail / Agent Team / Project Flow。轨迹是真实状态可驱动的控件，另外两个是自动场景插画。三者分别展示现在做到哪里、一句话展开成分工、想法形成任务结构。
3. 少填一点：Decision Card。三道合作偏好示例支持选择、自填、折叠和键盘操作；不把任何个人偏好预设为推荐答案。
4. 阶段衔接和结果亮相：Blur Crossfade / Cover Flow。前者处理局部文字与面板高度，后者让少量视觉作品卡有惯性、空间和反射。

正式引导仍保持上方 AI 角色、中间当前问题、下方阶段交互的构图。优先挑选能让输入、处理与结果产生关系的动作，不要求一个页面同时出现所有效果。

## 控件与插画分别怎么用

- Decision Card、Agent Trail、Writing Assistant、Prompt Library、Tag Input、Dropzone 可以承接实际交互，但仍需要业务状态与接口。
- Integration Beam 带互动，但连接状态只是场景演示。Integration Flow、Agent Team、Project Flow、Team Invite、Glass Folder 都不是实际任务或用户数据的管理界面。
- Cover Flow 适合六至二十个视觉对象；本页使用六张明确标注的示例作品卡，不用假人选凑推荐数量。Tilt Card 适合最终卡片亮相，编辑态不要跟着指针倾斜。
- Glass Folder 的原版针对浅色绘制，夜间对照仍保留白色展示底。Project Flow 通过原版 theme 参数切换深浅色。
- Writing Assistant 明确设为模拟语音，不申请麦克风权限。Dropzone 的队列和进度只在本地模拟，不读文件内容、不发送文件。
- Prompt Library 原版变量只识别拉丁字母等标识，演示保留 skills / goal 等变量，附中文描述；正式中文流程需处理实际标签呈现。

## 另一个完整模板候选

[Agent / Inbox](https://www.affectui.com/screens/inbox) 适合参考一次只处理一个问题、选项展开细节、提交确认后下一题滑入的完整节奏。它也包含任务栏和工作区，作为画像引导时应取逐题节奏与确认反馈，不能照搬后台信息架构。本轮只核验了官方文档，未把这一整套页面安装进本地对照库，避免把官方参考误写成已实现页面。
