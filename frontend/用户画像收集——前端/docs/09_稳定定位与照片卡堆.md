# 稳定定位、长资料卡与照片卡堆

> 历史版本。资料卡结构、桌面拖动优先与详情大外框已由 [第四版](10_长文资料与信息条推荐.md) 取代；角色定位、聊天宽度、素材来源仍保留参考价值。

2026-11-12，第三版。入口仍为 http://127.0.0.1:4199/guide 。本轮针对角色在拖动窗口时错位、资料卡外观、聊天空间，以及推荐页的照片卡堆和详情展开进行修改。主题和字体继续使用 Signalry，所有产出留在本专项目录。

## 角色如何定位

旧版把角色始终放在固定浮层里，再测量页面位置。连续改变窗口尺寸时，测量、动画和浏览器布局可能不同步，造成角色落后于内容。

新版只保留一个角色实例。停留时，角色直接挂在当前场景的真实位置元素下，宽高和位置随浏览器原生布局变化；移动仅在场景或当前助手头像发生变化时播放。转场期间缩放、滚动或改变可视视口，会取消转场并立即回到实际位置。长聊天中，角色由消息区自身的滚动裁切，不单独计算一个可能落后的裁切框。夜间仍为原版橙色，减少动态时为静态角色。

关键实现位于 [experience.tsx](../components/onboarding/experience.tsx)。React portal 的容器持续存在，位置变化不会创建第二只云朵。

## 资料卡的选择与实现

本轮重新查询了 AffectUI 与 Shadcn UI Kit，在线目录和源码查询可用。对照了 Social Profile card9、图片卡 card3、form-layout1，以及 AffectUI Settings Profile 和 Tilt Card 的使用说明。

- 资料卡采用 **Shadcn UI Kit Social Profile card9** 的封面、身份区域和内容主体结构，使用 Signalry Card 基础组件。封面改为主题色，身份头部展示称呼、核对状态和资料段数。
- 每段资料采用左侧标题／操作、右侧完整正文的编辑布局，手机改为上下排列。点击「编辑这一段」才展开多行编辑器，显示字数；内容和逐条可见性继续使用已有状态。
- 没有采用 Tilt Card 包裹长资料或输入框，其原说明也不建议让阅读和控制区域持续倾斜。
- 没有把账户设置模板里的邮箱、时区、密码等字段带进首次引导，也没有采用示例简介的短字数上限。

资料卡适配见 [profile-card.tsx](../components/onboarding/profile-card.tsx)，基础卡片见 [kit-card.tsx](../components/onboarding/kit-card.tsx)。原始 card9 和 card3 的源码记录存放在 docs/v3-source-snapshots/；实际组合在业务组件中完成，vendor 不变。

## 聊天的空间分配

第 4、6、7 阶段使用接近页面两侧的聊天布局。桌面左右各留 36px，手机各留 14px，不再限制在中间 820px 的窄栏。顶部的阶段标题压缩到一行，正文区获得剩余高度。

输入框位于可视页面底部。长对话在上方独立滚动，多行输入可以增长到有限高度，避免盖住全部正文。Plan 模式、跳过问题、继续完善、返回和本机保存状态均保留。长计划仍作为助手消息出现，正文可滚动阅读和编辑。

## 最后一页的照片与详情

桌面左侧为照片卡堆，右侧为当前卡片的详情。照片上只放身份、角色与少量标签，长描述留在详情区。卡片结构基于 **Shadcn UI Kit card3**，拖拽、堆叠、选择状态和展开动画由业务层组合实现，并非声称下载了官方完整刷卡模板。

- 左右拖动照片都表示看看下一张；同时保留上一张、下一张按钮和可聚焦的照片详情按钮。拖动不是唯一操作方式。
- 下一张接替当前照片，右侧资料与它同步。详情的背景从实际照片卡区域扩展至右侧，再显示内容；改变窗口尺寸会终止这段展开，避免拉伸到过时的位置。
- 「想认识」只加入名单，「暂不合适」移出本次列表；发送好友申请仍有独立的收件人和附言确认，不由刷卡动作触发。
- 最后一张不会自动循环或补充其他活动的人。没有更多候选会说明当前一组已看完；仍可回看、联系或选择普通浏览。
- 手机上保留照片卡堆，点击整张照片或「查看详情」会在同一画面向下展开详情，可以收起回到卡片。
- 照片来自 Kit 原示例引用的素材，已缓存到 public/guide/photos/；每张明确标注为示意配图，不表示照片里的人是本机虚构资料的主人。没有上传或抓取用户照片。

实现见 [candidate-deck.tsx](../components/onboarding/candidate-deck.tsx)。本次未改变活动隔离、可见性或真实服务接入范围。
