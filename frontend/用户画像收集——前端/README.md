## 打开引导与参考库

当前业务体验是 http://127.0.0.1:4199/guide 。点击「先用示例体验」可完整走通；也可以手动填写，或「什么都不填，先去看看」。已有草稿会恢复；需要从头体验时，在右上角设置中确认清空本机草稿。

当前入口是 http://127.0.0.1:4199/references 。默认打开背景组合实验室，可切换网格、色光和组合背景。选择「本轮新增」查看新增的 22 组；选择「边框」对比滑动描边、流动光框和反光卡面。

每项都有适用阶段、来源、演示限制、重播、全屏与浅色／夜间切换。组合方案单独标明，不计作新增的原版组件。用户认可现有参考可作为候选，不等于最终页面布局已确认。

## 旧样张（仅保留记录）

本机预览地址：`http://127.0.0.1:4199/`。需要预览服务正在运行。

这是一页以 **AffectUI 为主** 的关键元素交互预览。保留 Signalry 的主题、字体、容器、网格和控件层级，组合出上方 AI 形象、中间引导文字、下方交互内容的纵向舞台。

可以直接试这四个状态：

1. **认识你**：一句话输入、快捷建议、可展开的本地文件选择反馈。
2. **整理中**：形象切换、动态阶段、步骤展开、失败状态与重新播放。
3. **画像卡**：修改昵称与介绍、移除技能、调整示例字段的展示范围。
4. **聊想法**：多行输入、快捷发送、预设流式回复和停止输出。

右上角可切换浅色 / 夜间模式、减少动态效果。页面也尊重系统减少动态设置。

**本页不连接登录、上传、模型、画像保存或推荐服务。** 角色卡是虚构示例，回复与进度为预设演示。文件不会上传或读取内容；输入只留在本页内存，刷新后清空。浏览器只保存主题与动态偏好。

## 运行与检查

```sh
npm ci
npm run dev
```

其他命令：

```sh
npm run typecheck
npm run build
npm run verify
node scripts/verify-surface-references.mjs
node scripts/verify-guide-model.mjs
node scripts/verify-guide-v3.mjs
python3 scripts/verify-guide-v2-sources.py
```

verify 使用 Playwright 的 Chromium，需先启动本页服务；没有浏览器时执行 `npx playwright install chromium`。可通过 CHROMIUM_EXECUTABLE 指定已有 Chromium，通过 PREVIEW_URL 指定本机预览地址。测试结果与截图写到本目录 artifacts/，不影响原版预览。
