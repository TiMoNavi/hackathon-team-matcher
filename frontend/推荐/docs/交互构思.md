# TA 的世界，从一个人慢慢展开

V2 对应 2026-11-12 的追加需求。首屏是一次有节奏的发现过程：左侧稳定认识一个人，右侧遇到 TA 的作品、兴趣与合作意愿。读者有了兴趣，再下翻看细节。

## 双排卡组

桌面约 31% 放人物卡，约 69% 放作品舞台。右侧有六个持久卡片槽位：前排一大一小，后排三个露出标签，最后一个隐藏并退出键盘访问。卡片的主次尺度随排位变化，人物本身不会自动切换。

初次搜索结束后，卡组从左侧方向放大显现；春力曲线负责减速和小幅回弹。每轮停驻约 5.6 秒后换位，布局采用 Motion layout 的变换动画。后排标签、底部圆点都可以手动挑选。阅读或输入时暂停，避免正在读的内容突然换走。

作品卡提供可识别的画面：旅行路径、迷你网页、声音波形、想法纸片、协作消息、实验轨道。画面是演示插画，不冒充真实项目截图。大号标题、小号说明和标签形成阅读先后，完整文字保留在详情弹层和下方项目区。

## 悬挂信息

上方一条弧线串起城市、技能、兴趣、可用时间与小目标。挂牌缓慢摆动，节点轻微明暗变化。点击每个挂牌可看来源说明。窄屏减少同时展示的挂牌，其资料仍保留在其他卡片和完整详情里。

持续动态主要集中于低干扰的图形细节。主卡文字在停驻期间保持稳定，换位时才改变视线焦点。人物卡的微倾斜与原首页保持同一语气。

## AI 有自己的空间

底部中央为常驻输入框，右下角为独立云朵助手与观察气泡，右边缘为侧栏展开箭头。桌面翻页控件避开助手区域，主内容也为底部输入预留空间。

桌面侧栏宽 352px，打开后舞台与输入框一起左移。低于 1100px 时使用模态侧栏、独立续聊框、焦点限制和 Escape 关闭。手机保留小云入口，隐藏长气泡以减小内容遮挡。

气泡内容跟随当前人物及卡组侧面变化。发送需求后先出现短暂思考状态，再显示预写回复；用户可点建议按钮切换人物或将协作时间带到前排。切换人物保留当前对话。界面不代替用户发消息、建立关系或加入讨论。

## 搜索过程

首次进入和点击重新搜索，都显示四个阶段：确认当前活动、读取演示资料、寻找合作线索、整理推荐理由。由云朵、思考加载、渐亮文字、滚动数字、进度轨道和骨架共同表达过程。

这是明确标记的前端流程演示，约 3.4 秒结束。阶段计数为 0–4，不制造真实搜索完成率。搜索中禁用重复刷新；跳过会取消所有该轮计时器，直接展示卡组。

## 下翻后的资料

下方采用作品浏览 → 项目解释 → 经历与贡献 → AI 分析 → 试想清单的顺序。通过 CoverFlow、Tabs、Accordion、来源筛选和问题叠卡保持可探索性。清单可以勾选，合作状态可以改变，但都只保存在本次页面内存。

经历只用已有演示资料，不补写学校、公司和年份。AI 依据不呈现技术审计中的严重级别或警报数，改成可以继续沟通的资料线索。

## 动效边界

- 轮换暂停条件包括前排悬停、卡组键盘焦点、输入、详情弹层、侧栏、活动弹层、页面不可见与舞台离开视口。
- 手动挑选后保留自动轮换设置，焦点留在卡片时继续暂停阅读。
- 顶部暂停按钮停止装饰动画和自动轮换；正文仍完整显示，面板和按钮可继续操作。
- 系统减少动态效果时直接呈现稳定信息，不倾斜、自动换位或逐字闪现。
- 卡组使用位移/缩放过渡；长列表与作品细节不进行持续布局重排。

## 规范与后续

主题、字体、导航容器和圆角服从 [Signalry 规范](../../design-system/team-matcher/MASTER.md)及相邻首页。组件使用 Shadcn UI Kit 与 AffectUI，详见[组件清单](组件清单-V2.md)。所有新增内容在推荐目录中，V1 另行留档。

接入真实系统后，以服务端确认的当前活动和获准字段为唯一资料来源。资料不足时减少卡片或明确待确认，不跨活动补人、不虚构经历。业务规则仍引用[主应用交互设计](../../../docs/前端主应用交互设计.md)和[共享契约](../../../docs/共享数据与接口契约.md)。
