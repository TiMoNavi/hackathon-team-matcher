## Shadcn UI Kit：9 个基础组件

| 组件 | 页面用途 |
| --- | --- |
| Button | 搜索、翻页、提交、对话动作 |
| Card | 人物卡基础容器 |
| Avatar | 人物头像与切换入口 |
| Badge | 技能、资料类别与演示状态 |
| Input | 底部与侧栏输入 |
| Dialog | 项目详情、活动说明及侧栏交互基础 |

基础文件从已核验的首页模板复制，本轮通过 className 和外部布局适配，没有修改 components/ui 文件。额外沿用首页 Brand 和导航语言，但不把品牌标记另计入上述 25 个组件。

changelog2 的时间线布局被组合进经历区；card9 的封面、头像和个人动作层级延续自 V1；skeleton3 仅作查阅，最终占位使用 AffectUI Skeleton，不声称已采用该 Kit 区块。

## 业务组合与源码适配

ShowcaseBoard、HangingTags、ProjectArt、SearchExperience、AssistantCompanion 和 ProfileDossier 是本页组合组件，不冒充下载的库组件。图形以本地 CSS/SVG 绘制，无第三方素材或远端图片请求。

新增 AffectUI 文件位于 components/affect，是可适配业务副本。处理了 React 渲染阶段 ref 写入、Next 预渲染的时间读取、中文标点拆分、中文控件文案和全局动效偏好。视觉变量及外层样式映射到 Signalry；资料依据区隐藏不适用于人物推荐的审计警报统计。

所有来源、凭据及私有配置保持现有边界。组件 registry 的鉴权地址不写入本说明或代码。
