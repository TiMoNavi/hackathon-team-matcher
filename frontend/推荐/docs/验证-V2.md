# V2 验证记录

2026-11-12，验证入口为本机 4203 端口的生产构建。V1 的检查不计入本记录。

## 结果

- TypeScript、ESLint、Next 生产构建通过。
- 135 项浏览器检查通过，0 失败，0 运行或 hydration 错误。
- 中文实际使用 PingFang SC；英文展示使用 Bricolage Grotesque；英文正文使用 Inter。通过浏览器 CDP 检查实际字形来源。
- 九种尺寸覆盖 320–1920px 宽度，包含 1280×720 的短屏，以及 1100、1280、1440px 下展开助手的布局。

## 交互与布局

检查横向溢出、前排文字行高、卡内动作边界、桌面控制区与输入框分离、助手占位、完整资料位于首屏之后。逐一切换三个虚构人物的六个侧面，验证后排标签置前和资料弹层来源。

检查作品浏览、经历切换、项目折叠、清单勾选、合作状态、问题叠卡与 AI 依据筛选。对话覆盖底部发送、思考过程、预写回复、人物联动、协作卡置前、保留对话、手机模态和焦点恢复。

正常动效模式检查搜索阶段推进、禁止重复刷新、跳过清理、卡片停驻、自动轮换、悬停/输入暂停、全局暂停和暂停时正文及侧栏仍可见。减少动态效果模式检查静态布局与可操作性。

## 范围

本记录验证前端本地演示，没有调用真实 AI、发送消息或验证真实推荐服务。搜索进度是前端阶段，不是后台任务完成率。清单、收藏、状态与对话均为内存状态。

既有 Next.js 版本的升级提示仍存在，生产构建在提示后重试成功；依赖版本本轮保持与首页一致。当前仅提供本机预览，正式部署前应完成依赖升级和复验。
