# V3 验证记录

2026-11-12，验证对象为推荐目录最新生产构建，入口 127.0.0.1:4203。本轮数据独立于 V1/V2 的旧验证。

## 结果

- TypeScript、ESLint 和 Next 生产构建通过。
- 166 项浏览器检查通过，0 失败，0 运行或 hydration 错误。
- 实际字体通过浏览器 CDP 核验：Bricolage Grotesque 用于英文展示、Inter 用于英文正文、PingFang SC 渲染中文。
- 九种尺寸：1920×1080、1440×900、1366×768、1280×720、1100×900、1024×768、768×1024、390×844、320×740。
- 额外检查 1440、1280、1100px 下的桌面侧栏展开，及手机模态输入与焦点恢复。

## 核心修改与检查

推荐容器已扩宽；主要正文至少 14px，前排标题至少 16px。检查了横向溢出、卡内内容与动作边界、两行标题、独立的助手与输入空间、换人按钮避让。三个虚构人物各六个侧面均能置前和查看。

底部已经挂载真正的 AffectUI Chat Composer。检查多行自动增高、Shift+Enter 不发送、中文输入法 Enter 不误发、普通 Enter 发送、思考状态、预写回复、切人后对话保留和输入时暂停轮换。未显示未接通的文件权限或模拟语音控件。

下翻默认六行资料列表，每行有资料来源和详情入口；作品浏览与经历切换仍可使用。五维分析有完整依据、建议、待确认项；没有生成匹配百分比。动态图包含中心人物与五个维度，节点详情、表格高亮、表格切换解读均经过操作验证。

正常动效模式检查四阶段搜索、重复点击限制、跳过搜索、换卡之间的停驻、自动轮换、悬停 / 输入暂停、全局暂停后正文和侧栏仍可读、后排置前的动画终态。动态图在视口中继续切换，选中节点后停止轮换供阅读。

## 范围与限制

这是本地前端演示，没有调用模型、推荐服务或消息服务。搜索阶段与图谱连线均是界面演示；人物资料只有既有三个虚构人物，不补写学校、任职时间或匹配评分。所有清单与收藏都在本地内存中。

既有 Next.js 版本的安全升级提示仍存在；构建在提示后重试通过。本轮未扩展到依赖升级，当前仅本机预览，上线前应处理升级并复验。
