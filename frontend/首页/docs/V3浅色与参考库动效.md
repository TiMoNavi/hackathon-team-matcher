# V3 浅色与参考库动效

2026-11-12。用户认可 V2，要求参考本机 4199/references 和「用户画像收集——前端」目录继续增加动态效果；随后补充去掉深紫色背景。这两项要求一并实现，首页仍在独立实验目录，预览保持 4200 端口。

## 本轮变化

- 推荐理由区改用浅紫色面与深色文字。聊天区改为白色与浅紫色过渡，活动卡改为浅色玻璃卡；活动海报的深紫代码块也改成白色。
- 保留 Signalry 的主紫色按钮、lime 小面积强调、原字体和容器比例。深色文字仍用于可读性，页面不再出现原来的深紫大背景。
- 伙伴区加入 AffectUI ModelWheel。方向文字沿弯曲滚筒轮换，当前方向居中高亮；用于展示可遇见的开发者类型，不代表实时用户数、匹配结果或个人分类。
- Hero 加入 Kit Cosmic 的落地光束和溅散粒子，集中在侧面，避开标题与按钮。按实际容器宽高布局，手机减少光束数量。
- GitHub／简历／作品来源选择使用 Kit AnimatedBackground 的共享选中层。点击来源时，紫色选中面滑向对应按钮；原按钮语义和画像切换保留。
- 画像卡复用 GradientFloor 做柔光边缘组合，卡片内部保持白色。它是已有背景组件与卡片的组合，并非新的官方边框组件。
- 四个内容区的标题复用 TextReveal，滚动进入时逐字显现。中文字符可正常换行；暂停时立即显示完整文字。

## 动态与边界

全站暂停和系统减少动态效果继续生效。落地光束在暂停、离屏或后台时卸载动画层和计时器；文字滚轮停止自己的计时器和绘制循环。来源选中与画像内容仍可操作，降低动态时即时切换。

仍为本地交互原型，不读取真实 GitHub／简历，不运行模型或发送消息。卡片、人物、活动、画像和群聊内容均为演示。
