# V6.2 导航质感

2026-11-12，按用户要求美化原先近乎纯白的顶部导航。

保留 Signalry 的 1248px 容器、16px 圆角、字体与三组导航结构，对照 Shadcn UI Kit navbar2 的悬浮导航分组。选中态复用项目已有的 Kit AnimatedBackground 适配组件 AnimatedSelection，不新增依赖、不修改 components/ui。

- 使用浅紫磨砂背景、轻阴影与局部下缘色光，配色取自 Signalry 变量。
- 64px 导航内容区承载缓慢掠光，鼠标移动时出现局部反射；不增加高度。
- 四个章节入口增加细线图标。选中层跟随整屏场景状态移动，点击、滚轮和浏览器返回保持同步；用 aria-current 标记当前位置。
- 主按钮增加微渐变、内高光与独立箭头区域，暂停和菜单按钮使用 44px 点击区域。
- 手机菜单使用同一套材质与高亮；选中后收起并把焦点交回菜单按钮。菜单展开时隐藏底部滚动提示，避免与内容挤在一起。
- 手动暂停和系统减少动态效果均控制新增动效。

折叠导航仍为 66px，含顶部 16px 外边距和底部 6px 间距后总占用为 88px；展开菜单继续由页面网格按实际高度分配空间。

导航交互检查见 v6-navigation-verification.json，截图位于 screenshots/v6-navigation。桌面检查章节点击、滚轮、返回、鼠标反射与暂停；移动端检查 768/390/320px、菜单开合、选中态、焦点恢复和减少动态效果。实际字体通过浏览器平台字体信息核对，并查看桌面与手机截图。

验收：38 项导航检查与 43 项高度回归通过，运行错误为 0；TypeScript、ESLint 与生产构建通过。本机预览仍使用 4200，已从 frontend/首页 重新启动。
