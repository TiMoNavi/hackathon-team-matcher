# V2 视觉与动效

2026-11-12。本轮对应用户对边框、背景、文字与首屏气势的反馈。继续使用 Signalry 的主题、原始字体、1248px 主内容区、宽窄分栏和五段叙事，改动仅在本独立实验目录。

## 视觉调整

- Hero 标题在大屏增至最高 80px，小屏按实际中文宽度缩放。中心保留清晰阅读区；外围是大小、速度、方向不同的组队故事。
- 弹幕由单头像短条升级为双人头像与组队信息。完整故事卡和简短消息交错，少量 lime 色面强调相遇；故事与人物均为演示。
- 用柔和色面、玻璃高光和分层阴影代替重复灰框。输入控件、焦点和必要结构仍保留可辨识边界。
- 人物流采用白／浅紫交错卡面。推荐区采用浅紫人物卡、白色项目区、night 色 AI 理由区，通过面板层次区分信息。
- 背景、标题、轨道与卡片各有不同运动尺度。主要文字不随背景晃动，来源选择按钮保持静止。

## 动效与交互

- 导航右侧的全站暂停会停止持续装饰和自动播放。系统减少动态效果优先，并保留完整文字和手动交互。
- 弹幕以实际内容长度测量，无缝循环；暂停和恢复保留当前位置，悬停只减速。离屏和后台标签页停止弹幕播放。
- Hero 指针视差仅用于鼠标，触屏不触发；减弱运动时关闭。文本和主按钮不会被弹幕遮挡或拦截。
- 逐字显现不因暂停停在不可读状态。暂停 CSS 只命中持续动效，不冻结 Dialog、导航或确认反馈。
- 推荐卡支持按钮、左右方向键和触屏拖动；人物、项目信息和 AI 理由同步更新。
- 原画像确认、可见性演示、兴趣标记、本地群聊、活动加入均保留。没有接入真实 GitHub、简历解析、模型或消息接口。
