# V6 上下滚屏

2026-11-12，按用户明确要求移除底部翻页栏、页码、浏览模式切换及底部进度条。内容舞台向下延伸至视口底部。

六幕采用常见的垂直整屏切换。向下滚动时下一幕从下方进入，向上滚动时上一幕从上方返回。取消横向旋转、横向翻页和转场柔焦。

鼠标滚轮只处理纵向滚动；手机使用上下滑动。较长内容先原生滚动，开始于内容边界的新手势才切换相邻幕。向上返回时落在上一幕的内容底部，符合自然阅读方向。连续滚轮事件设有手势锁，防止一轮惯性跳过多幕。

保留桌面侧边章节定位、顶部导航、直接锚点、浏览器返回、上下方向键与 Page Up / Page Down。聊天、表单、弹层和横向人物条带保留自身操作。减少动态效果和全局暂停下仍能切换，只取消动画。

浅色主题、素材、呼吸浮动、鼠标流光和互动页尾均沿用上版。未新增依赖、未修改 components/ui 或参考工程。

## V6.1 顶栏与可用高度

2026-11-12，修正桌面滚屏后底部内容露不全、还需补滚一段的问题。根因是舞台用固定顶边距避让导航，而各幕中的插画、人物列表、聊天区和留白仍按连续长页的固定尺寸排列。

首页外壳改为 `auto minmax(0, 1fr)` 两行网格，高度为 `100dvh`。顶栏连同外边距、安全区及展开的手机菜单占第一行，内容舞台使用剩余空间，不再写死 88px / 86px 偏移。舞台作为尺寸查询容器，区块高度、间距与插画使用真实可用高度。

在桌面短屏中，画像、推荐和协作标题改为同一行的两段动态文字，推荐卡的选人圆点与辅助说明并排，避免空白挤占内容。人物列表、AI 插画和聊天窗口随高度调整。所有资料来源、推荐人选、加入按钮与说明仍完整保留。窄屏和放大后的长内容继续允许原生页内滚动，不用隐藏内容来制造整屏效果。

高度专项脚本为 `scripts/verify-height.mjs`，结果为 `docs/v6-height-verification.json`，截图位于 `docs/screenshots/v6-height/`。它检查六种桌面尺寸、六幕高度、人物及资料切换、上下各五次真实滚轮、手机菜单展开和视口高度变化。

验收结果：43 项高度检查、30 项滚屏回归全部通过，浏览器运行错误为 0；生产构建、TypeScript 与 ESLint 通过。桌面覆盖 1920×1080、1440×900、1366×768、1280×800、1280×720、1024×768；手机覆盖首屏和页尾完整展示、导航展开，以及长内容仍可滚动至末尾。
