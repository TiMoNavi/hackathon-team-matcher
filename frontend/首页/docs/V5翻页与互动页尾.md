# V5 翻页与互动页尾

2026-11-12，按用户本轮要求把连续长页改为默认六幕逐页体验。五个既有内容区之后，第六幕是重新组合的互动邀请页尾。保持 Signalry 浅色主题与本地演示边界。

## 浏览方式

- 底部前后按钮、页码、桌面侧边章节导航均可切换。
- 鼠标滚轮在当前页内容读完后切换整幕；同一段滚轮惯性不连续跳过多页。
- 手机可左右轻扫非交互区域，或使用固定底部前后按钮。较长的内容保留页内纵向滚动。
- Page Up / Page Down 和左右方向键可以翻页；表单、人物卡、群聊、弹窗保留自己的操作。
- 地址中的章节锚点支持直接进入，浏览器后退可返回上一章节。
- 左下角可切换连续浏览。此模式切换会重新挂载演示区，重置未保存的本地演示状态；同一逐页模式内切换章节保留状态。

## 材质与动态

- 翻页使用整幕位移、轻微三维旋转、缩放和柔焦叠化，过渡结束后文字恢复清晰。
- 鼠标带动淡色页面光斑；画像与理由卡增加沿边缘出现的局部流光。
- 画像卡与首屏故事增加轻微呼吸浮动。可阅读正文保持稳定，悬停或暂停时收住浮动。
- 非当前页不可聚焦或点击，自动演示暂停。减少动态效果与全局暂停均保留可用的翻页按钮。

## 页尾组件

采用 Shadcn UI Kit cta6 的居中邀请、错落人物条带结构，换为本项目已有的六位示例人物和一个“你的位置”入口。人物卡组合 AffectUI TiltCard；邀请语用 BlurCrossfade 随悬停、聚焦或点选切换。手机条带可横向浏览。

组件检索与源码通过现有双库 MCP 获取：cta6、carousel11、onboarding-screen5。carousel11 的计数与前后按钮、onboarding-screen5 的分段进度作为导航依据。整页演示控制器是本地适配，不宣称是上述库的现成全屏组件。未新增依赖，未修改 components/ui。
