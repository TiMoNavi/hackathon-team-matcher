# 首页中文文案

本文件是独立设计稿，依据冻结简介编写，不替代或改写原文。「同频」为本次展示名称。页面中的人物和活动为演示。

## 产品介绍

同频是一个帮助开发者在活动中找到队友的社交空间。参加同一场黑客松、开发者聚会或技术交流活动的人，可以在这里介绍自己、分享想法、认识伙伴，再通过聊天把合作向前推进。

AI 从你主动提供的 GitHub 公开资料、简历和作品中整理画像，帮助你表达技能、经历与合作期待。你确认后，资料才按你选择的范围展示。推荐会说明彼此在技能、方向和时间上的交集，让每一次打招呼都有一点依据。

## 首屏

**你的下一个队友，也在找你。**

你有想法，这里有人愿意一起做。
技能互补，方向合拍，相遇在同一场活动。

主按钮为「遇见我的队友」，次按钮为「看看故事怎么开始」。

弹幕讲述小小的相遇，例如「小满找到了 AI 搭档」「你写前端，我来写后端」「第一次黑客松，也有人同行」。全部是场景示意，不作为真实用户证言或运营数据。

## 认识队友

**这里有写代码的人，也有懂你想法的人。**

每一种热爱，都有人回应。

方向滚轮展示前端开发者、AI 工程师、产品设计师、后端开发者、开源贡献者、创意开发者与行动派队友。这是合作方向的文字示例，不是实时用户数据。

看看他们做过什么、正在寻找什么。下一次合作，也许就从一句「这个想法，我也喜欢」开始。

辅助说明为「同一场活动，更近一步」「发现与推荐，只发生在你加入的活动中」。

## AI 画像

**让 AI 认识你，也让队友读懂你。**

你写过的代码、做过的项目、认真打磨的作品，都比一张空白表单更懂你。把它们交给 AI，一起整理出真实、鲜活的自我介绍。

GitHub 展示「从代码认识你」，简历展示「经历也有故事」，作品网站展示「看见你的热爱」。

AI 帮你整理，展示什么、给谁看，始终由你决定。

## 推荐

**有些合拍，值得展开聊聊。**

认识一个人，也看看 TA 正在做什么。AI 帮你找到技能、兴趣和时间上的交集，最后的选择留给你。

左侧看这个人，中间看正在做的事，右侧读为什么值得认识。推荐理由只提供参考，合不合拍，聊过才知道。

## 开始协作

**聊到一起，就一起做点什么。**

从一句打招呼，到一个想法群。和伙伴一起聊方向、分任务，需要时，叫上 AI 帮忙理清下一步。

带上你的技能，也带上还没完成的想法。通过邀请码加入活动，遇见这次和你同场的伙伴。

## 收尾

**下一个好作品，从认识你开始。**

带着你的技能、好奇心，和还没来得及实现的想法。
剩下的，我们一起找到答案。
