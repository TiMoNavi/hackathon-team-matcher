## 必须遵守

### 对话布局补充（2026-11-11）

用户随后指定 Soho Chat App Template 作为对话布局参考。对话页的导航栏、会话列表、消息区和窄屏切换按 [chat.md](design-system/team-matcher/pages/chat.md) 对照 Soho；整体主题与字体继续遵循 Signalry。本补充优先于本文件中对所有页面布局的泛化要求，不扩展到其他页面。原版 Soho 预览用于对照，保留自身视觉与演示数据。

2026-11-12 用户指定 [对话 群聊页面](对话%20群聊页面/README.md) 为该专项前端的固定位置，并要求风格向相邻 [首页](首页/README.md) 靠拢。对话页面的源码、说明、参考快照及验收产出放在该目录。当前入口为 `http://127.0.0.1:4202/`，是独立内存演示，不代表真实消息服务已接通。

1. 核心页面必须沿用原模板的字体设置、字号层级、容器宽度、网格比例、留白、对齐、圆角、颜色和交互语言；只换紫色不算遵循模板。
2. 从原版组件、区块和主题开始复用或组合。不得重新制作一套主观风格板来代替原模板，不得拿此前被否定的中文样张作参考。
3. 英文标题使用原版 Bricolage Grotesque，正文使用 Inter。检查字体实际加载和渲染，不能只检查 font-family 字符串。中文实际字形与排版单独验证，不能把英文已加载等同于中文字体已确认。
4. 使用 shadcnuikit Skill 查找和复用组件；frontend-design、ui-ux-pro-max 等通用建议服从用户已指定的 Signalry 基准，不另选配色、字体或页面骨架。
5. 信息架构和业务行为遵循父级 AGENTS.md 与 [主应用交互设计](../docs/前端主应用交互设计.md)、[共享契约](../docs/共享数据与接口契约.md)。模板的营销导航、登录演示、客户数据和价格示例不作为业务规则。
6. 组件来源继续限定为 Shadcn UI Kit 与 AffectUI。新增功能部件统一到 Signalry 主题，不能带入另一套模板的视觉。
7. vendor 为原始快照；原版预览副本用于对照。业务改造在独立目标目录进行，不修改这两个基准。组件适配优先用 props、className、主题变量和外层布局，不直接改 components/ui 基础文件。
8. 凭据继续留在现有私有配置中；不读取、打印或复制 .local 内容到说明、日志或代码。下载沿用用户指定的 CollectUI registry，不自动换站点。
9. 验收同时比较桌面与手机截图、实际字体、布局比例和真实交互。构建成功、字体请求成功或模板能打开，都不能单独证明产品页面达到原版效果。
