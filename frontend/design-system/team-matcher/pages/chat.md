## 原版结构

```text
桌面（lg / 1024px 起）
┌────────┬──────────────────────┬───────────────────────────┐
│ 导航栏 │ 会话标题 / 状态入口  │ 联系人 / 群聊标题与操作    │
│ 80px   │ 搜索框               ├───────────────────────────┤
│        ├──────────────────────┤ 消息内容，可独立滚动      │
│        │ 会话列表，384px      │                           │
│        │ 可独立滚动           ├───────────────────────────┤
│ 个人项 │                      │ 底部消息输入区            │
└────────┴──────────────────────┴───────────────────────────┘

手机 / 窄屏
会话列表 + 底部导航 → 点选会话 → 全屏聊天 → 返回列表
```

- `h-dvh` 占据视口高度，会话列表和消息内容独立滚动。
- 导航 `w-20`，列表 `lg:w-96`，消息区 `min-w-0` 自适应、`lg:p-6` 留白。尺寸来自当前源码。
- 消息区分为顶部信息、中间滚动区、底部输入区；长内容不应撑宽页面。
- 未选择会话时展示空状态；窄屏选择会话后进入全屏层，返回后恢复列表。
- 资料和群详情按需打开 sheet/drawer，不固定占用第四栏。
- 会话条目包含头像、名称、摘要、时间和未读标记；资料详情与消息操作分别处理。

原版使用 DM Sans 与 Geist Mono，保持在原版预览中；正式业务适配沿用 Signalry 已确认的字体体系，中文效果另外核对。

## 业务边界

- 私聊、活动讨论、AI 对话明确标识；共享布局不等于共享成员、消息或权限。
- 好友与已有私聊不因切活动消失；不同活动的想法讨论独立。
- 状态动态、音视频、文件下载与群管理仅作模板参考，不据此承诺新增产品功能。
- 发送必须来自用户操作，前端内存演示不代表真实发送、存储或权限验证。
- 规则以 [主应用交互设计](../../../../docs/前端主应用交互设计.md) 和 [共享契约](../../../../docs/共享数据与接口契约.md) 为准。

## Skill 使用

使用 `shadcnuikit` 保留现成模板的布局、响应式与主题 token。通过 MCP 查询聊天页面目录，确认通用 Dashboard Chat App 与本次 Soho 独立模板的区别；实际使用已有 Soho 完整快照。

使用 `ui-ux-pro-max` 定向检索 `chat sidebar responsive navigation`，采用匹配的横向溢出、导航遮挡、键盘焦点和 viewport 检查；未采用无关的表格建议，也不生成替代原版的风格板。

正式适配还需修复原模板的可访问性缺口：会话行目前是 click div，应提供语义控件与键盘操作；部分图标按钮缺少可访问名称。原版保留这些现状供对照，不能称为已通过完整无障碍验收。
