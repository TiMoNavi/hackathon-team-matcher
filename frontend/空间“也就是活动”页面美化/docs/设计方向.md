# 第一版设计方向

活动名是视觉中心，首屏呈现人与创作的现场，下面进入稳定的论坛和日程。

- 沿用 Signalry token：白 #FFFFFF、文字 #13111C、主紫 #5B3DF5、浅紫 #F7F5FF、辅助紫 #EEEAFF、青柠 #D9F85F。
- 沿用 Bricolage Grotesque / Inter 本地字体，中文沿用首页系统栈并实际验证。
- 首屏中心标题和主次操作，外围少量活动装饰；主照片与右侧窄照片保留 Features 的宽窄层级。
- 桌面主体采用 64/36 论坛与赛程分栏，手机单列；完整论坛、日程和相册通过活动内标签切换。
- 动效集中于首屏光场、照片与标签指示器，信息正文保持稳定。
- 设计样例使用虚构的周末造物场与演示人物，图片为氛围素材。所有写操作只在当前页面内存生效。

对照需求复核：主视觉是活动现场与作品，直接提供论坛和日程；没有引入新的全站主导航或另一套色彩体系。活动页采用常规滚动，以便查阅与返回。
