# 背景、回帖与头像细化

更新于 2026-11-12。预览地址为 <http://127.0.0.1:4201/>。本轮围绕背景层次、论坛回帖和人物入口继续完善现有活动页，保留 Signalry 与相邻首页的字体、容器、色彩和布局比例。

## 设计处理

- 背景增加淡紫与青柠色光晕、低对比网格、照片外框与轻量卡片阴影；继续复用首页已适配的 AffectUI gradient-floor、tilt-card。
- 帖子卡片显示最新回复摘要。详情中的回帖采用头像、作者、楼层、时间与柔和气泡分层，自己的回复使用浅紫底色。
- 输入区支持多行文字、引用原回复、取消引用和空内容校验。关闭帖子后保留该帖草稿与引用对象；发送成功后清空输入，归档状态禁止回复。
- 点击头像或姓名打开基本资料卡，展示角色、简介、技能与本场合作意向。入口覆盖首屏伙伴、帖子作者、回帖作者和伙伴列表，支持触控、键盘、Escape 与焦点恢复。
- “查看个人主页”在新标签页打开对应人物，保留原活动窗口的草稿。主页展示同一人物的资料与本场初始帖子，并提供返回活动入口。

## 组件来源与实现

本轮继续采用 shadcnuikit 与 frontend-design；通用设计建议服从 Signalry。

| 部分 | 参考与落地位置 |
| --- | --- |
| 头像资料卡 | Kit avatar15 的点击 Popover、card9 的封面与头像层次；components/blocks/member-preview.tsx |
| 回帖与引用 | Kit chat-bubble2/message-list-item 的头像、气泡和时间布局；components/blocks/discussion-thread.tsx |
| 对应人物主页 | Kit card9 与活动原有主题；app/people/[id]/page.tsx |
| 视觉适配 | app/event-polish.css，在原活动样式后加载 |

来源源码见 [avatar15 与 card9](sources/avatar15-and-card9.md)、[chat-bubble2](sources/chat-bubble2.md)，来源指纹见 [sources.json](sources.json)。新增 Popover 基础组件原样取自 Kit；原有 8 个 Signalry 基础组件未修改。

## 人物路由与演示范围

本目录提供 /people/0 至 /people/6，分别对应当前演示身份与 6 位同场伙伴。相邻个人资料专项目前展示固定人物，不具备与本页人物 ID 匹配的入口，因此本次在授权目录内补齐可查看的演示落地页。未修改相邻项目或后端。

不存在或格式不匹配的人物编号显示“暂时找不到这位伙伴”，提供返回活动入口，不展示其他人的资料。当前 Next.js 流式响应可能返回 HTTP 200，同时输出 not-found 内容与 noindex；验证同时检查页面内容和人物信息缺席，不单凭状态码判断。

所有人物、活动与帖子均为虚构演示。回复与草稿只保存在当前活动窗口内存，刷新重置；人物主页仅展示初始演示帖子，不同步其他窗口的临时发帖。正式个人主页及权限需接入后端授权资料，本轮没有接通后端或发布真实内容。

## 验证结果

- TypeScript、ESLint 和生产构建通过。
- [主页面验证](verification.json)通过 61 项，覆盖 1440、1024、768、390、320px，四个标签的布局、业务状态、字体实际渲染与原有交互。
- [触控验证](touch-verification.json)通过 14 项，包含手机资料卡、对应主页、新标签页、嵌套回复头像与引用回复提交。
- [本轮专项验证](polish-verification.json)通过 40 项，包含资料身份匹配、7 个主页、无效编号、键盘焦点、引用与草稿、归档只读、窄屏边界和浏览器错误检查。
- 人工查看桌面与手机截图，检查头像资料卡、回帖气泡、引用输入区和对应人物主页。浏览器检查不代替完整跨浏览器、真实设备或后端联调验收。

复跑专项检查可使用 scripts/verify-polish.mjs；PLAYWRIGHT_MODULE 与 CHROMIUM_EXECUTABLE 可指定本机 Playwright 与浏览器。
