# 第一版组件选型

2026-11-12。主题、字体和布局沿用首页及 Signalry。

| 部位 | 选用来源 | 适配 |
| --- | --- | --- |
| 导航与首屏 | Signalry SiteHeader / Hero | 活动标题、照片展示、真实职责的按钮 |
| 概览布局 | Signalry Features | 1248px 容器、64/36 主辅比例、24px 卡片 |
| 论坛卡片 | Kit social-media-post1 | 活动话题、正文摘要、评论和点赞本地演示 |
| 日程 | Kit event-calendar1 / AgendaView | 按天议程与详情，沿用当前活动上下文 |
| 标签切换 | AffectUI segmented-control | Signalry token、触控尺寸与 tab 语义 |
| 首屏轻动效 | 首页已适配 AffectUI gradient-floor / tilt-card | 只用于展示区域，支持减少动态效果 |

检索过 Kit 日历 screen 与 AffectUI agent-activity / assistant-overview 等 screen。后两者以 AI 运行记录为主，不适合作为活动页面主体。没有另引入新的视觉模板。

## 第二轮：背景、回帖与人物入口

- avatar15：点击式头像 Popover，保留触发器、头像、信息、操作的布局。改成语义化 button，适配键盘与触控；外层统一 Signalry 主题。
- card9：复用封面、跨界头像与个人简介的结构，应用到资料卡与演示主页。不引入模板中的关注数或虚构社交关系。
- chat-bubble2/message-list-item：复用头像、气泡、时间的消息结构，改成论坛作者、楼层、引用和回复操作；不套用私聊的已读状态。
- AffectUI gradient-floor：继续使用首页已有实现，在外层 CSS 叠加浅紫与青柠光场、细网格和照片边框。

源码快照见 sources/avatar15-and-card9.md、sources/chat-bubble2.md，新增 components/ui/popover.tsx 原样来自 Kit。
