# 设计与组件来源

2026-11-12，用户要求保存于「对话 群聊页面」，风格向「首页」靠拢。

## 两个基准的分工

**Soho 提供对话结构。** 桌面导航栏、会话列表、消息区三栏；1024px 以下切为列表与对话两个视图；列表和消息分别滚动；详情抽屉按需展开；输入区固定在消息区底部。保留原版的源码快照与运行副本，适配代码独立。

**首页提供视觉语言。** 同频标志、人物头像、Bricolage Grotesque 标题 / Inter 正文、中文 PingFang SC 后备字形、1248px 容器、浅紫网格、白色圆角表面、紫色按钮及青柠点缀来自相邻首页。聊天区维持安静的阅读背景，页面外围保留可暂停的轻微光晕。

桌面实际列宽为 76px / 324px / 剩余空间；1024–1200px 为 68px / 292px / 剩余空间，以便放入与首页一致的 1248px 外框。原版 Soho 的 80px / 384px 参数仍在原版预览中保留。

## 实际复用

| 部分 | 来源与适配 |
| --- | --- |
| Button、Input、ScrollArea、Bubble、Dialog、Drawer、Popover | Soho 的 `components/ui`，复制后未修改，通过 props 与页面 CSS 适配 |
| 字体、图标、头像与品牌组件 | 相邻首页的本地文件 |
| 主题变量 | 首页 `app/globals.css` 的 token、base 与 theme 段 |
| 会话结构与消息更新方式 | 参考 Soho，按稳定会话 ID、独立草稿和内存演示重新组织 |
| 图标 | Soho 原有 lucide-react 依赖 |

共 33 份组件、字体与头像文件通过 SHA-256 对照，见 [source-integrity.json](source-integrity.json)。

## Skill 的采用

- `shadcnuikit`：从已有 Soho 模板与基础组件开始，使用 Base UI 组件接口，不重新编写基础弹窗或抽屉。
- `frontend-design`：对齐用户选择的首页视觉、层级与留白，不引入另一套色板或字体。
- `ui-ux-pro-max`：检查窄屏溢出、独立滚动、焦点、输入法、减少动效与实际字体。

## 演示范围

页面使用虚构人物、两组同活动讨论和四条已有私聊。新建会话、草稿、附件与设置只保留于页面内存，刷新即重置。详情中的活动范围说明表达后续产品边界；当前没有活动切换器、服务端权限校验或跨用户即时通讯。

附件通过本机 Blob URL 展示与下载，不上传、不读取文件正文。删除待发附件或页面卸载时释放相应 URL。界面不展示虚构的真人输入状态、服务器已送达或真实已读回执。
