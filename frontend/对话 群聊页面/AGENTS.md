# 对话与群聊前端约定

- 本目录为用户于 2026-11-12 指定的固定产出位置，相关页面源码、快照、说明与验证记录留在这里。
- 布局参考 Soho，视觉对齐相邻 `../首页`；继承父目录 AGENTS.md 和正式业务契约。
- 保留本地 Inter、Bricolage Grotesque、首页品牌与主题。中文字形要实际检查。
- 用户要求提供日夜切换，首次访问默认日间且不跟随系统；手动选择可在浏览器记忆。主题位于 html，以覆盖门户弹窗；维护时同时检查夜间和日间。
- 基础组件来源为 Shadcn UI Kit，`components/ui` 保持源文件原样；用 className、props 和外层样式适配。
- 原版 `../vendor` 和 `../experiments/*original-preview` 为基准，不得随业务改造修改。
- 当前为内存演示，不得描述为已接后端、已发送真实消息、已执行服务端权限或已持久化。
- 不同活动的讨论不能混用，已有私聊不随活动切换消失；后续接入要以服务端授权契约为准。
- 消息发送、建群和附件选择均须用户操作，不增加自动发消息或自动回复。
- 好友申请独立于会话：收到的可接受/婉拒，发出的只能撤回；接受后才加入联系人与唯一空私聊。保留请求版本和终态校验。不能把本地状态演示说成服务端授权或真实好友关系。
- 保持桌面独立滚动、窄屏列表到聊天切换、输入法保护、减少动效和可访问控件名称。
- 视觉精修集中在 app/polish.css；只让背景缓慢持续运动，交互反馈按需触发。暂停与系统减少动效必须同时覆盖页面和门户内容，隐藏页面暂停背景。
- 修改后按需要运行 typecheck、构建与浏览器脚本，并更新 docs 内的记录。
