## 二、按“是否把它装进项目”分类

| 类别 | 站点 | 对依赖树的影响 |
|---|---|---|
| 会进入 `package.json` | Motion、HeroUI、FlyonUI、Hugeicons 图标包 | 有升级成本，需关注 breaking change |
| 复制源码进仓库（不产生运行时依赖） | 21st、ReUI、Shadcnblocks、Shadcn Studio、ShadcnSpace、Shadcn UI Kit、Efferd、React Bits、Arc UI、BeUI、BoardUI、AffectUI、MagicUI、ThreeUI | 无版本锁定，但需自行维护 |
| 只用于生成 / 出稿 | Aura Build、Figma 套件、各站 MCP 与 AI 工具 | 不进入运行时 |

这一区分是本项目最关键的判断：**复制源码型**组件受第三方版本变更影响小，适合长期自有产品；**依赖型**动画引擎（Motion）则相反，但它是多个复制型库的共同底座。

## 四、需要注意的公开事实

- **“购买”按钮的含义不同**。多数站点是一次性买断并给源代码；21st 是会员制（每日 2 次免费复制）；Shadcn Studio 是订阅；Aura Build 是信用点。
- **Radix UI 与 Base UI 双轨已成常态**。Shadcnblocks、Shadcn Studio、ShadcnSpace、Efferd 都同时发布两套 primitive，选择时需与项目现有 `components.json` 保持一致，否则会出现两套 primitive 混装。
- **官方 endorsement**。ReUI 首页展示了 shadcn/ui 作者对本注册表的认可，属于少见的官方背书信号。
- **许可证差异**。ReUI 免费层明确为 MIT；BeUI 免费层标注 MIT 可商用；其余站点免费层许可条款需逐站确认，“免费”不等于可商用。
