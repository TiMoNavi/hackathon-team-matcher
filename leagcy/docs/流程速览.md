# 用户流程快速参考

## 🎯 5 步完成配对

```
1️⃣ 登录注册           → 看到技能弹幕，产生兴趣
2️⃣ 智能采集 (3分钟)   → AI识别简历 + 对话引导
3️⃣ AI推荐队友         → VSCode式界面，右侧AI助手
4️⃣ 发送配对申请       → 双向确认后获得联系方式
5️⃣ 创建/加入星球      → 团队可视化 + AI点评
```

## 🔐 隐私保护机制

```
阶段 1: 浏览推荐
  ✅ 可见：昵称、角色、技能、项目标题
  ❌ 不可见：真实姓名、联系方式

阶段 2: 发送申请
  ✅ 对方可见：你的完整画像
  ❌ 仍不可见：联系方式

阶段 3: 双向确认
  ✅ 互相可见：微信、邮箱、电话
  ✅ 可以开始对话

阶段 4: 加入星球
  ✅ 星球成员间：所有信息互通
```

## 🎯 推荐轮换策略

```
第 1 批：技能互补
  "这些人的技能正好补充你缺的部分"
  → [后端A, 设计师B, 算法C]

第 2 批：经验匹配
  "这些人和你经验相当，容易协作"
  → [全栈D, 前端E, 后端F]

第 3 批：个性契合
  "这些人的协作风格和你很搭"
  → [后端G, 产品H, 运营I]

第 4 批：随机探索
  "也许你会喜欢这些'惊喜选项'"
  → [跨界J, 新人K, 专家L]

防重复：7天内推荐过的不再推荐
```

## 🎨 视觉风格

**配色**
- 主色：科技蓝 #3B82F6 + 渐变紫 #8B5CF6
- 成功：绿色 #10B981
- 背景：浅色 #F9FAFB / 深色 #111827

**动效**
- 卡片翻转：推荐卡片可翻转查看详情
- 连线动画：团队图谱的连线有呼吸效果
- 弹幕滚动：首页平滑滚动
- 粒子加载：AI 分析时的粒子效果

**响应式**
- 桌面：VSCode 三栏布局
- 平板：隐藏左侧栏，用 Tab
- 手机：单栏 + 底部导航

## 📞 关键数据

**用户体验目标**
- 信息采集：≤3 分钟
- 推荐响应：≤2 秒
- 匹配准确度：>85%
- 配对成功率：>30%

**通知策略**
- 即时：收到申请、申请被接受、星球消息
- 每日 10:00：今日推荐 3 位新队友
- 每周日晚：本周总结
