# 完整用户流程设计

> 基于实际使用场景的端到端交互流程

---

## 🎯 设计理念

- **降低填写门槛**：AI 自动识别 > 引导式对话 > 手动填写
- **吊起用户兴趣**：首页展示真实技能弹幕，营造活跃氛围
- **类恋爱匹配体验**：双向确认、隐私保护、渐进式公开
- **VSCode 式布局**：左侧导航、中间内容、右侧 AI 助手

---

## 📱 完整用户旅程

```
登录/注册 → 技能弹幕首页 → 智能信息采集 → 个人画像生成 
    ↓
AI 对话推荐 → 发送配对申请 → 双向确认 → 获得联系方式
    ↓
创建/加入星球 → 团队可视化 → AI 点评团队 → 推荐缺失角色
```

### 3.2 推荐轮换机制

#### 核心原则

1. **去重**：上次推荐过的，短期内不再推荐
2. **多样性**：每批推荐来自不同的匹配维度
3. **公平性**：避免某些人被过度曝光

#### 推荐批次策略

```typescript
interface RecommendationBatch {
  batch_id: string
  strategy: 'complementarity' | 'experience' | 'personality' | 'serendipity'
  candidates: User[]
  reason: string
}

// 第 1 批：技能互补优先
{
  strategy: 'complementarity',
  reason: '这些人的技能正好补充你缺的部分',
  candidates: [后端A, 设计师B, 算法工程师C]
}

// 第 2 批：经验匹配
{
  strategy: 'experience',
  reason: '这些人和你经验相当，容易协作',
  candidates: [全栈D, 前端E, 后端F]
}

// 第 3 批：个性契合
{
  strategy: 'personality',
  reason: '这些人的协作风格和你很搭',
  candidates: [后端G, 产品H, 运营I]
}

// 第 4 批：随机探索 (Serendipity)
{
  strategy: 'serendipity',
  reason: '也许你会喜欢这些"惊喜选项"',
  candidates: [跨界人才J, 新人K, 资深专家L]
}
```

#### 防重复推荐规则

```typescript
async function getNextRecommendations(userId: string) {
  // 1. 获取历史推荐记录
  const history = await getRecommendationHistory(userId, days: 7)
  
  // 2. 过滤掉已推荐的用户
  const excludeUserIds = history.map(h => h.recommendedUserId)
  
  // 3. 获取当前批次策略
  const lastStrategy = history[0]?.strategy
  const nextStrategy = getNextStrategy(lastStrategy)
  
  // 4. 根据新策略搜索
  const candidates = await searchCandidates({
    strategy: nextStrategy,
    exclude: excludeUserIds,
    limit: 5
  })
  
  return candidates
}

function getNextStrategy(lastStrategy: string) {
  const rotation = [
    'complementarity',  // 技能互补
    'experience',       // 经验匹配
    'personality',      // 个性契合
    'serendipity'       // 随机探索
  ]
  
  const currentIndex = rotation.indexOf(lastStrategy)
  return rotation[(currentIndex + 1) % rotation.length]
}
```

## 🎬 总结

这套流程设计的核心思想：

1. **降低门槛**：简历上传 → AI 识别 → 对话补充，不是冷冰冰的表单
2. **营造氛围**：首页技能弹幕，让用户感受到活跃的社区
3. **保护隐私**：渐进式公开，双向确认才能联系
4. **增加粘性**：星球系统、团队可视化、AI 点评
5. **类恋爱匹配**：推荐卡片、配对申请、查看详情，借鉴成熟的匹配模式
6. **VSCode 式界面**：开发者熟悉的布局，降低学习成本

下一步：**原型设计** → **前端实现** → **后端 API** → **测试上线**
