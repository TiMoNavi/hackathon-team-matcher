## 二、前端技术栈

### 2.1 框架选择：Next.js 14

**为什么选择 Next.js？**

| 特性 | 优势 | 适用场景 |
|------|------|----------|
| **App Router** | 服务端组件、流式渲染 | AI 对话流式输出 |
| **API Routes** | 前后端一体化开发 | 快速原型开发 |
| **SSR/SSG** | SEO 友好 | 落地页营销 |
| **Vercel 部署** | 零配置、免费额度 | MVP 阶段省钱 |
| **TypeScript** | 类型安全 | 减少 bug |

**安装**：
```bash
npx create-next-app@latest hackathon-matcher \
  --typescript \
  --tailwind \
  --app \
  --src-dir \
  --import-alias "@/*"
```

**替代方案**：
- **Nuxt 3**：如果团队更熟悉 Vue
- **Remix**：如果需要更细粒度的数据加载控制
- **Vite + React**：如果不需要 SSR

**为什么选择 Zustand？**

- TypeScript 支持好
- 性能优秀
- Bundle 小（1KB）

**安装**：
```bash
npm install zustand
```

**示例**：
```typescript
// store/userStore.ts
import { create } from 'zustand'

interface UserProfile {
  id: string
  nickname: string
  skills: string[]
  teamStatus: 'seeking' | 'teamed' | 'casual'
}

interface UserStore {
  profile: UserProfile | null
  setProfile: (profile: UserProfile) => void
  updateSkills: (skills: string[]) => void
}

export const useUserStore = create<UserStore>((set) => ({
  profile: null,
  setProfile: (profile) => set({ profile }),
  updateSkills: (skills) => set((state) => ({
    profile: state.profile ? { ...state.profile, skills } : null
  }))
}))

// 使用
import { useUserStore } from '@/store/userStore'

function ProfilePage() {
  const profile = useUserStore(state => state.profile)
  const updateSkills = useUserStore(state => state.updateSkills)
  
  return <div>{profile?.nickname}</div>
}
```

**替代方案**：
- **Jotai**：原子化状态管理
- **Redux Toolkit**：适合大型应用
- **Context API**：简单场景够用

### 2.5 表单处理：React Hook Form + Zod

**为什么这个组合？**

✅ **优点**：
- React Hook Form：性能好、无不必要的重渲染
- Zod：类型安全的表单验证
- 两者集成完美（`@hookform/resolvers`）

**安装**：
```bash
npm install react-hook-form zod @hookform/resolvers
```

**示例**：
```typescript
// components/ProfileForm.tsx
import { useForm } from 'react-hook-form'
import { zodResolver } from '@hookform/resolvers/zod'
import { z } from 'zod'

const profileSchema = z.object({
  nickname: z.string().min(2, '昵称至少 2 个字符'),
  skills: z.array(z.string()).min(1, '至少选择一个技能'),
  contact: z.object({
    wechat: z.string().optional(),
    email: z.string().email('邮箱格式不正确').optional(),
  })
})

type ProfileFormData = z.infer<typeof profileSchema>

export function ProfileForm() {
  const { register, handleSubmit, formState: { errors } } = useForm<ProfileFormData>({
    resolver: zodResolver(profileSchema)
  })

  const onSubmit = (data: ProfileFormData) => {
    console.log(data)
    // 提交到 API
  }

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <input {...register('nickname')} placeholder="昵称" />
      {errors.nickname && <span>{errors.nickname.message}</span>}
      
      <button type="submit">提交</button>
    </form>
  )
}
```

## 三、后端技术栈

### 3.1 运行时：Node.js + TypeScript

**为什么选择 Node.js？**

✅ **优点**：
- 前后端统一语言（降低学习成本）
- 生态丰富（npm 包多）
- 异步 I/O 性能好（适合 API 网关）

**替代方案**：
- **Python + FastAPI**：适合 AI/ML 重度场景
- **Go**：性能更好，但学习成本高
- **Bun**：更快的 Node.js 替代品（但生态不成熟）

### 3.2 Web 框架：Hono

**为什么选择 Hono？**

✅ **优点**：
- 🚀 极快（比 Express 快 4 倍）
- 🪶 轻量（12KB）
- 🔒 类型安全（TypeScript 原生支持）
- ☁️ Edge Runtime 友好（Cloudflare Workers）
- 🎯 现代 API（类似 Express 但更优雅）

**安装**：
```bash
npm install hono
```

**示例**：
```typescript
// server/index.ts
import { Hono } from 'hono'
import { cors } from 'hono/cors'

const app = new Hono()

app.use('*', cors())
app.use('*', logger())

// 用户路由
```

**替代方案**：
- **Fastify**：性能好，插件生态丰富

- **NestJS**：重量级，适合大团队

**推荐**：
- **MVP 阶段**：Hono（快速开发）
- **生产阶段**：Fastify（插件多，社区成熟）

### 3.3 ORM：Prisma

**为什么选择 Prisma？**

✅ **优点**：

- Schema 定义清晰（类似 GraphQL）
- 迁移管理方便
- 查询性能好
- Prisma Studio（可视化数据库管理）

**安装**：
```bash
npm install prisma @prisma/client
npx prisma init
```

**Schema 示例**：
```prisma
// prisma/schema.prisma
generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

model User {
  id              String   @id @default(uuid())
  nickname        String
  realName        String?
  contactWechat   String?
  contactEmail    String?
  githubUrl       String?
  
  capabilityScore Json?    // 存储多维评分
  credibilityScore Int     @default(50)
  
  teamStatus      TeamStatus @default(SEEKING)
  visibility      Visibility @default(PUBLIC)
  
  skills          UserSkill[]
  projects        UserProject[]
  sentRequests    MatchRequest[] @relation("Requester")
  receivedRequests MatchRequest[] @relation("Target")
  
  createdAt       DateTime @default(now())
  updatedAt       DateTime @updatedAt
}

model UserSkill {
  id          String  @id @default(uuid())
  userId      String
  user        User    @relation(fields: [userId], references: [id])
  skillName   String
  skillLevel  Int     // 1-5
  verified    Boolean @default(false)
  evidenceUrl String?
}

model MatchRequest {
  id          String  @id @default(uuid())
  requesterId String
  requester   User    @relation("Requester", fields: [requesterId], references: [id])
  targetId    String
  target      User    @relation("Target", fields: [targetId], references: [id])
  message     String?
  status      RequestStatus @default(PENDING)
  createdAt   DateTime @default(now())
}

enum TeamStatus {
  SEEKING
  TEAMED
  CASUAL
}

enum Visibility {
  PUBLIC
  PRIVATE
  PASSIVE
}

enum RequestStatus {
  PENDING
  ACCEPTED
  REJECTED
}
```

**使用**：
```typescript
import { PrismaClient } from '@prisma/client'

const prisma = new PrismaClient()

// 创建用户

```

**替代方案**：

## 四、AI 服务层

### 4.1 LLM：Claude API (Anthropic)

**为什么选择 Claude？**

✅ **优点**：
- 对话质量高（尤其中文）
- Function calling 稳定
- Context window 大（200K tokens）
- 价格合理（比 GPT-4 便宜）
- 安全性好（拒绝越狱）

**定价**（Claude 3.5 Sonnet）：
- 输入：$3 / M tokens
- 输出：$15 / M tokens

**成本估算**：
```
每次对话：约 2K tokens 输入 + 500 tokens 输出
成本：0.002 * $3 + 0.0005 * $15 = $0.0135 ≈ ¥0.10

1000 次对话：$13.5 ≈ ¥100
```

**安装**：
```bash
npm install @anthropic-ai/sdk
```

**示例**：
```typescript
import Anthropic from '@anthropic-ai/sdk'

const client = new Anthropic({
  apiKey: process.env.ANTHROPIC_API_KEY,
})

const message = await client.messages.create({
  model: 'claude-3-5-sonnet-20241022',
  max_tokens: 1024,
  messages: [
    { role: 'user', content: '我是前端开发，想找个后端队友' }
  ],
})

console.log(message.content)
```

**替代方案**：
- **GPT-4 Turbo**：更强大，但贵 2 倍
- **DeepSeek V3**：便宜（¥1/M tokens），但质量稍差
- **Gemini Pro**：Google 的，免费额度大

### 4.2 Embeddings：OpenAI text-embedding-3-small

**为什么需要 Embeddings？**

用于技能语义相似度搜索：
- "React" 和 "前端框架" 应该匹配
- "Node.js" 和 "后端开发" 应该匹配

**定价**：
- $0.02 / M tokens
- 每个技能约 10 tokens → 10000 个技能 = $0.002

**安装**：
```bash
npm install openai
```

**示例**：
```typescript
import OpenAI from 'openai'

const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY,
})

async function embedSkills(skills: string[]) {
  const response = await openai.embeddings.create({
    model: 'text-embedding-3-small',
    input: skills,
  })
  
  return response.data.map(d => d.embedding)  // 1536 维向量
}

// 使用
const embeddings = await embedSkills(['React', 'Node.js', 'TypeScript'])
// [[0.123, -0.456, ...], [...], [...]]
```

**替代方案**：
- **Cohere embed-multilingual**：多语言更好
- **Voyage AI**：专为检索优化
- **本地模型（sentence-transformers）**：免费但需要部署

**安装**（SDK）：

```typescript
const client = new QdrantClient({ url: 'http://localhost:6333' })

// 创建集合

  vectors: {
    size: 1536,  // text-embedding-3-small 的维度

  },

// 插入用户向量
await client.upsert('user_skills', {
  points: [
    {
      id: userId,
      vector: skillEmbedding,
      payload: {
        nickname: '张三',
        skills: ['React', 'TypeScript'],
        teamStatus: 'seeking',

    },

// 搜索相似用户
const results = await client.search('user_skills', {

```

## 六、部署方案

### 6.1 前端部署：Vercel

**为什么选择 Vercel？**

✅ **优点**：
- Next.js 官方，零配置
- 自动 HTTPS
- 全球 CDN
- 预览部署（每个 PR 一个预览链接）
- 免费额度够用

**免费额度**：
- 100GB 带宽/月
- 6000 分钟构建时间/月
- 无限网站

**部署**：
```bash
npm install -g vercel
vercel
```

**替代方案**：
- **Netlify**：类似 Vercel
- **Cloudflare Pages**：全球更快
- **Railway**：前后端一起部署

---

### 6.2 后端部署：Fly.io

**为什么选择 Fly.io？**

✅ **优点**：
- 支持 Docker
- 全球多区域部署
- 自动 HTTPS
- PostgreSQL/Redis 内置
- 便宜（$5/月起）

**免费额度**：
- 3 个 shared-cpu VMs
- 3GB 持久化存储
- 160GB 出站流量/月

**部署**：
```bash
# 安装 Fly CLI
curl -L https://fly.io/install.sh | sh

# 初始化
fly launch

# 部署
fly deploy
```

**替代方案**：
- **Railway**：更简单，但贵一点
- **Render**：类似 Heroku
- **AWS Fargate**：适合大规模
