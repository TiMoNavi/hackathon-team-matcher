### 3.2 AI 对话界面（Chat UI）

#### ✅ **Vercel AI SDK** (官方推荐)
- **链接**：https://sdk.vercel.ai/
- **文档**：https://sdk.vercel.ai/docs/ai-sdk-ui/chatbot
- **特点**：
  - ✅ 开箱即用的 `useChat` hook
  - ✅ 流式响应（streaming）
  - ✅ 支持多模态（文本、图片、文件）
  - ✅ Function calling 内置支持
  - ✅ React/Vue/Svelte 都支持
  
**示例代码**：
```typescript
import { useChat } from 'ai/react'

export default function ChatInterface() {
  const { messages, input, handleInputChange, handleSubmit } = useChat({
    api: '/api/chat',
    initialMessages: [
      { role: 'assistant', content: '你好！我是组队助手小派' }
    ]
  })

  return (
    <div className="flex flex-col h-screen">
      {/* 消息列表 */}
      <div className="flex-1 overflow-y-auto p-4">
        {messages.map(m => (
          <div key={m.id} className={m.role === 'user' ? 'text-right' : ''}>
            <div className="inline-block p-3 rounded-lg bg-blue-500 text-white">
              {m.content}
            </div>
          </div>
        ))}
      </div>
      
      {/* 输入框 */}
      <form onSubmit={handleSubmit} className="p-4 border-t">
        <input
          value={input}
          onChange={handleInputChange}
          placeholder="输入消息..."
          className="w-full p-2 border rounded"
        />
      </form>
    </div>
  )
}
```

### 3.4 向量数据库（Vector DB）

用于技能语义搜索和相似度匹配。

| 方案 | 类型 | 优点 | 缺点 | 价格 |
|------|------|------|------|------|
| **Pinecone** | 托管 | 简单、稳定、无需维护 | 贵 | $70/月起 |
| **Qdrant** | 自托管/托管 | 开源、功能强、可自托管 | 需要运维 | 免费（自托管） |
| **Chroma** | 本地/云 | 轻量、易用 | 功能较少 | 免费 |
| **Weaviate** | 自托管/托管 | 功能强大 | 复杂 | 免费（自托管） |
| **PostgreSQL + pgvector** | 扩展 | 无需新数据库 | 性能一般 | 免费 |

**推荐**：
- **MVP 阶段**：Qdrant Cloud（免费 1GB）
- **生产阶段**：自托管 Qdrant（省钱）

**示例**：
```python
from qdrant_client import QdrantClient
from qdrant_client.models import Distance, VectorParams

# 初始化
client = QdrantClient("localhost", port=6333)

# 创建集合
client.create_collection(
    collection_name="user_skills",
    vectors_config=VectorParams(size=1536, distance=Distance.COSINE),
)

# 插入用户技能向量
client.upsert(
    collection_name="user_skills",
    points=[
        {
            "id": user_id,
            "vector": skill_embedding,  # 1536 维向量
            "payload": {
                "skills": ["React", "Node.js", "TypeScript"],
                "experience": 3,
                "availability": "seeking"
            }
        }
    ]
)

# 搜索相似用户
results = client.search(
    collection_name="user_skills",
    query_vector=query_embedding,
    limit=10,
    query_filter={
        "must": [
            {"key": "availability", "match": {"value": "seeking"}}
        ]
    }
)
```

### 4.3 合成数据生成

如果真实数据不足，可以用 AI 生成测试数据：

```python
def generate_fake_users(count=1000):
    """
    用 Claude 生成测试用户
    """
    prompt = f"""
    生成 {count} 个真实的开发者画像（JSON Array）。
    
    要求：
    1. 多样性：前端30%、后端30%、全栈20%、设计10%、其他10%
    2. 真实性：技能等级符合经验年限，有合理的"不完美"
    3. 包含字段：
       - name, skills (array), experience_years, projects (array),
         github_url (fake), availability, preferred_role
    
    示例：
    {{
      "name": "张三",
      "skills": [{{"name": "React", "level": 4}}, {{"name": "CSS", "level": 3}}],
      "experience_years": 2,
      "projects": [{{"name": "电商后台", "role": "前端开发"}}],
      "availability": "seeking"
    }}
    """
    
    # 批量生成
    users = []
    for i in range(0, count, 50):  # 每次生成 50 个
        response = claude_api.generate(prompt)
        users.extend(json.loads(response))
    
    return users
```

**成本**：1000 个用户 ≈ $5-10

## 五、核心算法参考

### 5.1 学术论文

#### Team Formation (ACM RecSys)
- **算法**：基于图的团队组建
- **核心思想**：把人看作节点，技能互补看作边权重
- **适用场景**：需要组建完整团队（3-5 人）

#### Skill-based Matching (IEEE)
- **算法**：技能向量余弦相似度
- **核心思想**：技能 Embedding + 向量搜索
- **适用场景**：1v1 匹配

#### Collaborative Filtering (Netflix)
- **算法**：协同过滤
- **核心思想**：根据历史组队数据预测未来匹配成功率
- **适用场景**：有大量历史数据后使用

### 5.2 工业界实践

#### Lunchclub Matching Algorithm
- **博客**：https://blog.lunchclub.com/how-we-match
- **技术**：
  - User Embeddings（用户向量化）
  - Graph Neural Network（图神经网络）
  - Reinforcement Learning（强化学习优化长期匹配质量）

#### Tinder ELO Rating
- **核心**：每个用户有一个隐藏评分
- **机制**：匹配成功 → 双方评分靠近，拒绝 → 分数差距拉大
- **启示**：可用于动态调整推荐策略

## 十、总结

### ✅ 已验证

1. **市场需求真实存在**
   - Reddit 高频提问
   - Devpost 大量"找队友"帖子
   - 多个团队尝试解决

2. **技术完全可行**
   - 有多个开源参考项目
   - AI 技术成熟（LLM + Embeddings）
   - 学术界有理论支持

3. **有明确差异化空间**
   - 现有方案都不够完善
   - 对话式 AI 交互是创新点
   - 反马太效应机制是核心竞争力

### ⚠️ 需要注意

1. **避免重复造轮子**
   - 用 Vercel AI SDK 而非自己写聊天界面
   - 用现成的 Skill Taxonomy
   - 用 Claude API 解析简历

2. **先验证再开发**
   - 不要一上来就写代码
   - 先用现成工具拼凑原型
   - 小规模测试匹配效果

3. **关注核心价值**
   - 匹配质量 > 界面炫酷
   - 解决资源错配 > 功能堆砌
   - 用户留存 > 一次性使用

### 🎯 建议路线

```
Week 1-2: 技术调研 + 搭建原型
Week 3-4: 生成测试数据 + 算法开发
Week 5-6: 小范围真实验证
Week 7-12: MVP 开发（如果验证通过）
```

**不要一开始就投入 6 周开发 MVP，先用 2 周验证核心假设！**
