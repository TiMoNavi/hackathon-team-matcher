| 回退 | UI 开关／原生入口、兼容性、必要恢复步骤；禁止盲目卸载 |
| 提交 | 分支、提交主题、记录 ID；完整 SHA 在后续回执补记 |
| 推送 | 远端分支 SHA 比对结果；失败则标 blocked，不能虚写成功 |
| 遗留 | 下一任务、是否阻塞最低闭环、需要用户处理的重大事项 |

## 完成声明规则

只有独立子任务、实际验证、文档和提交／推送证据齐全，才把实施批次标 done。任何必需登录、群聊、讨论或推荐未完成，最终仍须注明“最低闭环未完成”。不得把本轮草案、官方说明、mock 页面或过去的单模块测试称为目标应用已接通。
