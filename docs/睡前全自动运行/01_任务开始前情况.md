> 状态：已批准计划的任务开始前基线，现发布于 `docs/睡前全自动运行/`；不是应用运行验收。
> 调查日期：2026-11-12。下文保留开始调查时的源码、工作区及决策快照；文档发布与后续状态以 [task](task.md) 和 [实施记录](03_实施记录.md) 为准。未执行应用测试、真实登录、模型调用、迁移或部署。

## 1. 本轮用户已确认的边界

1. 当前采用 HumHub 基座与插件化整合，不重新建设 FastAPI 后端。旧设计中的业务规则仍需对照，但不能把旧技术选型或 mock 当成现有实现。
2. 本轮先完成计划和相关文档，批准后才启动实现。
3. 最低交付是**真实 GitHub 登录、邮箱验证码登录 → 邀请加入活动 → 画像确认与隐私 → 当前活动发现/推荐 → 好友申请、私聊、建群、入群确认和想法讨论邀请**，不是六个页面能打开。
4. 两种真实登录必须先打通；配置缺失时阻塞相关闭环，不能用测试账号替代验收。
5. 优先采用 React 独立页面插件，同源资源由 HumHub 提供，保留现有源码目录，不混入旧框架样式。
6. 允许对已有、获授权的 AI 与邮件配置做小规模真实验证，不新建付费资源；本轮尚未做这些验证。
7. 后续使用独立工作分支，每个可验证批次审查、记录、提交和推送；不自动合并。
8. 初次子agent调用因默认模型不可用失败。用户随后报告六类代理的用户级配置已更新为 `TIMO GPT/gpt-6-sol`、`medium`、`long_context`，显式参数测试成功；**当前会话仍使用旧默认值，自动继承尚未验证**。须重载 VS Code 并新建会话，用不传这三项覆盖参数的实际子任务验证默认读取与日志。此前仅继续计划与文档，不启动代码修改；`long_context` 配置不代表实际 token 容量上限已验证。

## 2. 证据等级

- **源码事实**：本轮读取到文件、版本、接口或保护逻辑。
- **既有报告**：过去在特定环境中的验证；不是本轮重跑，也不代表新前端已接通。
- **待验证**：运行状态、真实配置、浏览器联调和对外服务，不依据文件存在判为通过。
- **拟实施**：设计建议与任务，不冒充已存在的 API 或功能。

## 6. 风险与阻塞

| 编号 | 问题 | 必须如何处理 |
|---|---|---|
| B01 | 两个 explore 子agent曾返回 `400 The requested model is not supported`，无有效报告；用户已报告显式参数测试成功，但本会话仍用旧默认值 | 重载 VS Code 并新建会话后，无覆盖参数验证默认配置及实际子任务结果；此前只推进文档，不把显式调用成功当作自动继承成功 |
| B02 | GitHub OAuth、可投递邮件验证码及浏览器授权尚未真实核验 | 收齐合法配置并验收真实登录；缺失即阻塞相关闭环 |
| B03 | 前端长文、正式确认时点和五阶段后端不匹配 | 保留用户体验，扩展领域能力，不静默截断或提前公开 |
| B04 | 推荐生产依赖未完整核验 | 逐一装配和测试历史、预算、provider，普通发现保持 0 次 LLM |
| B05 | 群聊和想法讨论加入确认缺口 | 作为最低交付必做，不再推迟到可选后续 |
| B06 | 原生 Module.disable 具有卸载／清设置语义 | UI 撤回与数据模块停用分开；不能用后台“禁用”当无损回滚 |
| B07 | 根导航与专项、源码之间有状态漂移 | 更新当前入口与对应契约；所有完成声明带证据等级 |
