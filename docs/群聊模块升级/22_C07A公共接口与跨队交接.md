# C07-A1 公共接口与跨队交接

2026-11-13。面向首页、画像和总专项集成人。此页是当前增量索引；[12通用接口目录](12_首页画像通用社交与聊天接口.md)保留旧批次验收，不回写其历史结论。后端0.4.0已通过固定隔离验证，主预览未部署；群正式页面与群正文尚未开放。

## 可直接复用的源码

| 调用需求 | 共用入口 | 当前边界 |
|---|---|---|
| 已有获准私聊的列表、历史、已读、发送、附件 | [client.ts](../../frontend/对话%20群聊页面/integration/src/chat/client.ts) 的 createChatApi | 必须有真实 conversationId 和逐会话权限；无按人物自动建私聊能力 |
| 建立空普通群、发邀请、邀请详情、接受／拒绝／撤回、退出 | [group-http.ts](../../frontend/对话%20群聊页面/integration/src/chat/group-http.ts) 的 createGroupApi | 独立导入；仅已有合格好友可被owner邀请；接受才建立成员 |
| 群命令校验、幂等键、DTO、动作态与晚到结果隔离 | [GROUP-MODE](../../frontend/对话%20群聊页面/integration/GROUP-MODE.md) | 显式用户动作；未知结果保留原键原输入，不自动重试；尚无跨刷新持久恢复 |
| 从活动卡片或合法公开帖发好友申请 | 由N08唯一写者交付普通业务适配 | 聊天不另建好友关系、请求历史或来源授权；不能拿群邀请代替好友申请 |
| 想法的活动讨论 | C08消费N09发布／资格／已有会话永久关联 | 当前元数据关联不能授予消息、成员或跨活动访问权 |

createGroupApi必须从当前原生登录bootstrap取CSRF及expectedActorId，apiBase固定同源/api/v1。完整七方法、参数、错误及示例以GROUP-MODE和[20运行合同](20_C07A群生命周期持久化与API.md)为准，避免在首页／画像复制另一份客户端。群客户端不加入旧ChatApi；群ID不得传给只开放direct的页面深链或正文接口。

## 好友仍复用原版

原生当前好友与屏蔽事实继续是权威。当前群资格读取原生启用账号、双向好友、双向屏蔽及原生friendship开关，并在事务中重新锁读。隔离工具为虚构账号建立关系仅是测试前置，不能称为已交付“加好友API”。

N08需要冻结并交接：event_card／public_post合法来源、真实申请ID与expected_version、接受／拒绝／撤回、永久幂等和终态历史、当前关系投影、唯一私聊绑定。聊天不把设计中的/api/v1/connection-requests或/connections当作已注册能力；首页／画像接线前以N08真实回执为准。公开帖作者入口按公开帖授权，不误套同活动要求；活动卡片申请仍验证当前活动。

## 下一批任务分配

1. **C07-A2 后端**：先补群列表／邀请收件箱及当前成员投影的最小读取合同，再接群正文与成员期历史；包括退出、重入、附件及原生旁路。复用原生message／user_message／message_entry，不另存消息正文。
2. **C07-B 前端**：在A2合同稳定后挂载建群、邀请待办和正式群会话；消费真实结果，再做双账号浏览器。既有视觉由聊天目录维护，全局首页／画像只调用共用入口。
3. **N08 所有者**：提供上述普通好友与唯一私聊接口，聊天消费交接，避免两队重复实现。
4. **C08 聊天与N09接口协作**：群和活动讨论分开；按想法活动与Space隔离，永久绑定和资格撤权先明确，再接消息。
