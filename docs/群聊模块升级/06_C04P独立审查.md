## 4. 新代码负例矩阵

本表为首次审查前列出的验证矩阵，最终离线覆盖与结果见第 7 节。内存测试只证明对应用例，不证明真实 session、并发数据库、旧入口或通知保护。

| 范围 | 最小负例 | 必须得到的结果 |
|---|---|---|
| actor | 未登录；请求伪造他人 actor；A 响应到达时已切 B | 明确 401/拒绝冒充；B 不显示 A 的列表、消息或错误残留 |
| 会话授权 | 第三人、缺成员记录、缺状态、未准入旧会话、未知类型 | 无权/不存在采用不可披露结果；不返回 title、计数、最后消息或成员 |
| 授权版本 | 首次授权后、读数据期间撤权；成员退出/重入；权限代次变化 | 返回前重验或等价一致性保证；旧结果不得继续投影 |
| 私聊范围 | 当前活动为空或从 A 切 B；好友失效后分别读/发 | 合法私聊不因切活动消失；读/发由各自权限决定 |
| cursor 绑定 | 改字节、换 viewer/会话/筛选/排序/权限版本；讨论换活动 | 拒绝重用；签名不是唯一校验，不把外来 position 当可信授权 |
| cursor 有效期 | 到期、超 15 分钟、异常未来签发时间、畸形/超长 token | 有明确验证与过期结果；无无限期或异常扩大有效期 |
| 分页 | cursor 与 after_seq 同传；非法 limit；同时间戳；seq 空洞/墓碑；多页增量 | 默认 24、最大 48，输入拒绝一致；升序、边界严格、无漏重，无全量读兜底 |
| 未读 | 自己发送、系统事件、删除占位、不可读历史、seq 空洞 | 按已锁定 kind/方向与获准范围计算；不返回未读会话数或简单序号差值 |
| 已读 | 回退、重复、越过获准最大位置、引用不可见位置、写时撤权、并发先高后低 | 真实授权内单调合并；不得越界，撤权不写；列表读取不改变 read_seq |
| 客户端失败 | 401/403/404/410/503、HTML 响应、畸形 DTO、跨会话数据 | 分类处理，不把错误伪装为空列表/成功，不回填 fixture |
| 晚到响应 | logout/reset、账号切换、权限变化、切会话后旧请求成功或失败 | 取消之外仍校验请求代次/actor/权限上下文；旧成功和旧错误都不能污染新状态 |
| 安全投影 | 富文本、未知 sender、跨会话 entry、未经授权附件/成员 | 文本安全显示；未知/失权投影明确，拒绝或剔除不得伪造原始事实 |
| 构建隔离 | 内存 adapter、测试 fixture 或未就绪客户端进入正式 shell | 正式入口保持 C03 无数据壳；离线实现不意外触发业务请求 |

群的 pending 邀请、join_seq 边界、退出/重新加入与跨 Space 讨论本批仅可作为拒绝或内存场景；生产启用须后续合同及全入口回执。

本轮发现的缺口已闭合。

- 后端校验请求、已存和单调合并后的 read_seq；除 0/join 基线外，必须对应同会话当前获准的真实消息/墓碑。空洞/未来位置由坏适配器负例证明拒绝并回滚；sender 可见投影不得改变原作者 ID。
- 前端拒绝 deleted+available sender、read=false 的成功正文投影、错误的 direct 历史起点及低于群历史边界的 read_seq。
- AUTHORIZATION_CHANGED / CURSOR_CONTEXT_CHANGED 的真实后端 409 清除全部旧摘要与正文；取消后的已观察 401 仍交给 session 所有者。同 session 清全局，已换 session 的晚到 401 不影响新账号。
- 列表 data 与消息/已读 context 均传 authorization_revision。空增量也能使已缓存 sender 投影失效；刷新历史接受新授权页时清除全部旧列表，跨 revision 续页不能合并。
- 增补了首次 list/detail 并发、较低 revision 晚到、拒绝后再次重放旧响应的负例。同 session 保留最高已见 revision；清缓存、403/404 或撤权错误不能降低水位。仅清除/替换 session、reset、dispose 重置版本域。
- [AccessReader](../../backend/protected/modules/matcher-chat/domain/ports/AccessReader.php) 已明确 viewer 维度持久单调版本要求；进程重启或缓存淘汰不得回退。真实存储恢复策略尚未实现，不由内存结果代替。
