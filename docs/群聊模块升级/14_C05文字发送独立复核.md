# C05 文字发送独立复核

2026-11-12 启动，2026-11-13 收尾冻结（Asia/Shanghai）。本轮源码与离线独审完成，发现的重放、未知结果和输入边界问题已修复并复核；已核对 root 执行的限定隔离 HTTP／SQL／浏览器报告，可通过本批已准入 direct 文字发送与前端接线范围，不作群聊、完整好友流程或生产放行结论。独审只写本文件及 [首页画像通用接口目录](12_首页画像通用社交与聊天接口.md)，源码只读；不操作数据库、服务、Git 或凭据。

## 当前核对事实

- 原生 friendship 双向关系及双向屏蔽可以作为已准入 direct 的当前发送资格事实；不等于 N08 来源、接受、历史、唯一绑定已经交付。
- 原生 ReplyForm 保存会触发附件、通知和原生已读副作用；AbstractMessageEntry 保存还会先更新会话、后处理富文本与刷新缓存，不能当作无副作用 append。
- 当前读取投影会剥离 HTML 标签；纯文本写入必须采用可往返的安全原生编码，保留原文，不因读写转换悄然改变幂等正文。
- root 已锁定幂等范围为 conversation＋sender＋client_message_id，trim 只判空；本轮使用新合成发送夹具并保留旧八条消息和已读。此处记录实施约束，不代表数据库验收已经执行。

## 复核范围

1. 身份、关系、屏蔽与会话锁的顺序、缺失行插入竞争和原生 cancel/block 并发。
2. 当前授权先于重放；同键同内容、同键异内容、跨会话／发送人、未知结果重试及持久限流。
3. 原生唯一正文、seq 与回执原子性，回滚／错误路径，不启用全局守卫豁免。
4. 明确点击发送、IME、双击、切会话／身份晚到结果、清除失败草稿与禁止隐式重试。
5. 旧写入口、非聊天功能与通知隔离；真实 SQL／HTTP／浏览器证据和离线测试分别记录。

## 源码结论

- 发送先检查当前完整授权，再查询永久 receipt；关系撤销后旧键不能绕过。配置 gate 不等于单个会话 send 权限。
- 数据库实现使用 REPEATABLE READ／当前锁读，除聊天总锁外还锁真实用户、设置、双向好友与双向屏蔽主键缺失范围。原生关系写者不使用聊天锁，真实并发顺序仍须单独证据。
- 原生 entry、seq、receipt 在既有事务／savepoint 内落库；raw SQL 写适配未调用 ReplyForm、notify、富文本处理或关闭全局 NativeGuard。提交后仅清原生未读计数缓存，未承诺通知或送达。
- HTML 实体编码经既有 NativeProjection 往返后保留原始文字，标签、实体、组合字符、CR／LF 和 emoji 未因发送逻辑改变。格式错误默认 HTTP 422；CSRF 400 与正文格式失败不同，接口目录已据实际 ChatException 对齐。
- 公共客户端构造与深链 helper 无 I/O，无 React、好友写入或 get-or-create；来自首页／画像的会话 ID 仍须服务端授权。

UI 0.2.0 的 Navigation 仍只精确替换原生 inbox 项；本次只将 takeover 标签改为“聊天”，未改变十字段 bootstrap 或扩大授权。README 与页面标题的旧“只读／不提供发送”文案已修正，前端构建和发布由 root 负责。

以上范围内未发现修复后新的可复现授权或幂等绕过；该结论不覆盖原生 AR 关系副作用、真实死锁、群聊、附件、通知、跨活动讨论或 N08。
