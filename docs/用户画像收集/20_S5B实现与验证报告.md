## 当前可以完成的流程

用户主动提交本人网站或一段文字，后端保存私有结构化文本、定位段落和明确字段候选。用户选择候选后进入普通资料草稿，核对确认，再继续已有规则补问、画像草稿和展示范围确认。全局资料继续复用，下一 Space 的活动专属信息从独立上下文开始。

GitHub、简历、网站和粘贴文字共用一套来源接口与存储。P5 不依赖 P2 引导页面；未来前端可读取能力、提交来源、展示候选并调用原有草稿 API。现有鉴权仍使用 HumHub 登录会话与 CSRF，正式前端接入时需要对应适配。

本阶段采用明确字段规则，模型调用为 0。自由描述保留为本人原文，AI 语义提炼、针对性问题和自然表达属于下一阶段 S6。

## 来源行为

| 能力 | 已实现行为 |
|---|---|
| 网站身份 | 规范化输入 URL 的哈希区分来源；原输入地址保留，最终响应地址单独记录 |
| 本人声明 | web/text 请求携带 ownership=self，记录 self_declared；候选仍由本人核对 |
| 文字身份 | 去除 UTF-8 BOM、统一换行后按正文哈希区分，保留其余内容 |
| 去重与刷新 | 同源重复导入复用已保存结果；网站刷新只读取服务端保存的原地址；修改文字作为新来源 |
| 失败恢复 | 网络/解析失败保留稳定错误状态，网站首次失败仍保留可显式重试的地址 |
| 候选采纳 | 校验来源与草稿版本、归属及候选证据；同值去重，保留手填值和既有隐私 |
| 原文保护 | 快照仅本人可读，列表省略原文，响应 no-store；普通资料不包含未采纳原文 |
| 删除 | 清除全部来源快照并撤销任务结果，已明确采纳的草稿或确认资料按普通资料规则保留 |

具体请求体、刷新方式、错误和依赖见 [S5-B API 合同](19_S5B网站与文字来源约定.md)。来源读取与外部 I/O 在数据库事务外执行，最终保存再次检查版本与删除状态。

## 网站读取范围

网站读取使用静态 HTML 或 text/plain。每跳重新校验全部 DNS 地址，固定实际连接 IP，关闭自动跳转和代理，并保留 TLS 校验。危险地址验证使用合成适配器，不实际访问内网。

网站网络总预算 15 秒，最多 3 次跳转、累计 1 MiB；DNS 子进程每次最多 3 秒，单次 HTTP 最多 10 秒，受剩余总预算限制。抽取正文最多 256 KiB，粘贴文字最多 128 KiB。运行依赖 PHP CLI、proc_open、cURL、DOM 和 mbstring。

HTTP 401/403 明确返回访问失败。HTTP 200 的登录提示或验证页可能成为未确认文本，用户需核对；解析器处理静态正文，不执行页面 JavaScript 或计算外部 CSS。动态站点可以改用粘贴文字。完整边界与测试依据见 [独立验收](21_S5B独立后端验收.md)。
