2026-11-11。本文记录独立执行的后端验收，范围来自 [S6 实施约定](22_S6实施约定.md)。独立验收完成，S6 专项 250 项及接合后原规则/来源回归 188 项通过。补充 SQL / worker 验收发现的 F1 日志计量问题已由实现代理修复，并经过独立实际命令复验。本文不代表主预览已部署或真实网关验收已完成。

## 环境与边界

- 只使用合成账户、资料、模型响应与隔离数据库。独立验收不读取 `.local/`，不连接真实模型网关。
- 真实指定模型验收由主 agent 单独执行，本文在取得去敏统计后仅注明该证据的执行人和范围。
- 专用测试检验端口实际行为与 HTTP / SQL 结果；静态代码核对只作为补充。
- 不修改产品实现、前端 assets/views、HumHub core/vendor、参考工程或冻结原稿。
- 隔离库使用专用 audit 前缀，HTTP 仅监听本机 8097；测试路由只允许合成账户。真实 HumHub session、CSRF、SQL 持久化和独立 CLI worker 均参与验收。注入引擎仍经过实际 P6 输出验证器。
- 独立验收新增的全部测试均为真实模型请求 0。没有使用私有原文、真实 GitHub 回调或浏览器前端作为通过依据。

### 完整流程与权限

实际跑通文字来源导入 → AI 提取 → 本人选择候选并采纳 → 明确确认资料核对 → AI 问题 → 选项、自由文本和跳过答案 → AI 综合 → 本人编辑草稿 → 明确确认可见性。

- 提交返回 queued / HTTP 202，读取、幂等重放、普通规则路径均不触发模型。
- 未登录、缺 CSRF、缺幂等键、跨账户 session / task / apply / answer 均被拒绝；来源版本与 section 必须属于本人所选来源。
- AI 提取和采纳都不会直接确认资料。新增采纳字段为 authenticated，已有手工 private 简介和联系方式保持原值、原范围。
- 每批保存 3–8 个问题。服务端稳定选项不可由模型改码、改标签或改用途；自由填写是独立的最后入口，不能伪装成普通选项，且每题允许跳过。
- 综合只生成可编辑草稿。本人修改后的文字与范围在最终确认后保留，非好友读取不出现 private / friends 字段或原始资料。新 Space 的活动专属上下文为空。
- 模型生成结构没有确认、发布、授予权限、切换 owner 或调用任意工具的入口；非法字段被整次拒绝。

### 任务状态与并发

- 独立端口检查与实际 SQL 引擎边界均验证模型执行发生在事务和应用锁之外。
- 同键同请求只产生同一任务；同键不同负载冲突。候选采纳重放不重复应用。
- 排队取消不调用引擎，执行中取消保留实际调用统计但不安装迟到结果。
- 手工草稿版本、答案、来源版本、来源删除或 Space 资格发生变化时，旧任务不能覆盖新数据；失效结果不返回，实际 SQL 读取确认 input / result 被清理。
- 最大活动任务数、单日任务数、最多三次显式尝试均有独立检查。失败读取不隐式重试，平台错误不静默降级到规则。
- 120 秒执行租约在第 119 秒仍 running、第 120 秒变 failed / AI_WORKER_INTERRUPTED；未知调用数为 null，accounting_complete 为 false。
- 显式重试创建独立任务。超时旧 worker 晚到时仅补实际计量，不安装结果、不改变新任务；真实 SQL 和实际空闲 watch 循环也已验证回收而不产生模型调用。

### 输出、提示注入和网络边界

- 三类输出的根结构、字段 schema、JSON 容器类型、来源版本、section、资料和答案引用均经实际验证器检查；空或重复证据、未知字段、跨范围引用和跳过答案引用被拒绝。
- 结构化字段必须与显式答案及服务端映射一致；模型不能凭仓库文字推断性格，不能凭合法引用增加未提供的城市或角色标签。
- 既有 headline / bio 不能由新模型输出覆盖；对未确认手工草稿的再次综合保留原文、原范围并提供冲突提示。
- 自然语言简介/标题保守继承所有已供给全局资料的最严格范围，包括未被模型引用的 private 联系方式。
- 提示注入文字只作为 user 数据进入请求。模型固定、无工具参数、不可由资料指定端点；HTTPS、TLS 校验、禁重定向、禁代理和 netrc、连接与总超时均用注入 curl 执行器核验，没有发出网络请求。
- 严格 JSON 拒绝围栏、尾随文字、数组根、嵌套重复键和 Unicode 转义后的重复键。错误响应不回传私有正文或异常链；已知 usage 保留，缺失或自相矛盾的 usage 保持未知。

真实调用 AiWorkerController::actionRun，并注入未携带可信计量的异常。任务存储正确记录 llm_calls = null，但命令输出使用空合并默认值，输出成 0，且缺少 accounting_complete。补充套件第 21 项复现失败。

## 已验证的能力限制

自然语言语义真实性不能由 schema 和合法 evidence 引用证明。独立构造的标题以真实可用的 TypeScript 技能条目为引用，却自称获奖并管理千人团队，仍能通过 prose 验证；输出保持 private，也没有确认或覆盖已有字段的能力。这是实际复现的限制，不是语义验真通过。

按本轮确认的产品边界保留 headline / bio 自然改写，不增加脆弱词汇白名单。用户仍须在可编辑草稿中核对并确认内容；结构化事实和性格字段继续要求显式证据及服务端映射。不得将本报告的 schema / 权限 / 隐私通过表述成“AI 文案已经核实真实”。

本验收覆盖后端 HTTP 与 SQL，不覆盖正式前端、浏览器可用性、真实 GitHub OAuth 回调或生产环境。真实指定模型的可用性与质量由主代理另行执行；独立测试没有借用网关成功来代替本地边界检查。
