# S5 独立真实网页验收

2026-11-11。独立测试子代理使用 Playwright 操作本机 Microsoft Edge，**56 项检查通过**，涉及 136 次页面业务 API 请求。测试在 S5 隔离数据库中使用新建合成账号执行，保留的截图也只含合成资料。

## 验收方式

资料选择、文件上传、候选采纳、逐条隐私、问题回答和最后确认均通过实际网页控件操作。浏览器调用真实 HumHub 页面与 /api/v1 服务，后端写入隔离 MySQL；测试没有替换页面脚本或业务 API 返回。只读 API 用于核对保存结果、版本、对象归属与访客可见范围。

GitHub 端到端用例使用服务端固定的合成外部传输，身份关联通过原生 AuthClientUserService 建立。测试保留真实原生身份查询、P3 读取编排、结构映射、P1 来源存储及 P2 页面流程。它验证账号识别和流程接合，不等同于实际浏览器跳转 GitHub 并完成 OAuth 回调。

另外执行了真实 GitHub 公共 API 冒烟，验证固定官方来源的数字用户 ID 查询与响应结构；无 token、无身份写入，也未保存返回的公共资料。见 [公共 API 证据](sources/s5-github-public-api_2026-11-11.json)。

| 场景 | 实际操作与核对 | 结果 |
|---|---|---|

| 首次读取 | 浏览页面不发起来源读取，明确开始填写后自动导入；本次合成源共 4 次服务端外部适配调用 | 通过 |
| 主页与项目材料 | 保存公开简介、项目 README 和独立的个人主页 README，候选关联结构化段落 | 通过 |
| 复用和刷新 | 页面刷新、继续原流程均复用来源；主动刷新后来源版本推进，适配调用累计为 8 次 | 通过 |
| 采纳与手填 | 将候选带入本次全局草稿，保留手工标题；导入本身不确认或公开资料 | 通过 |
| GitHub 完整流程 | 采纳、核对、补问、规则画像、范围预览、最终确认；普通资料读取相同结果 | 通过 |
| 删除和再次进入 | 删除后本人原文入口返回 404；确认资料保留；再次进入不自动重抓，页面提供明确重导入口 | 通过 |
| 无 GitHub 关联 | 如实显示当前预览未配置登录，简历上传与手填仍可使用 | 通过 |
| 简历四种格式 | TXT、DOCX、文本层 PDF、MD 均通过真实 multipart 上传并实际解析中文资料 | 通过 |

| 解析失败 | 损坏 PDF 保留失败状态；页面可重试并推进版本，也可删除该来源 | 通过 |
| 本人边界 | 其他用户不能读取来源原文；公开资料中没有原文、快照和 README 标记 | 通过 |
| 隐私与完成 | 导入简介设为仅本人，模拟预览及实际访客均不可见；最终确认保存经历 | 通过 |
| 手机与键盘 | 390px 隐私页面无横向溢出，使用 Enter 执行最终确认 | 通过 |
| 运行状态 | 无 JavaScript 异常、HTTP 500 或浏览器跨源请求 | 通过 |

所有来源与画像处理均使用 rules。文档解析器和 GitHub 读取器没有模型客户端，本次流程模型调用数为 0。

## 验证边界

浏览器为 Chromium 内核，手机验证采用 390 × 844 视口模拟。本轮未执行 Safari、Firefox、屏幕阅读器或负载测试。键盘检查覆盖最终确认操作。简历均为合成文档，不代表所有真实版式或扫描件都能解析；复杂 OCR 与 AI 提炼仍属后续能力。

真实 GitHub OAuth 回调尚未在本次浏览器验收中执行。完整账号关联步骤需要运行环境配置 GitHub OAuth 应用，现有页面会显示实际可用状态。测试中的固定 GitHub 外部传输仅由隔离路由安装，不用于主预览。
