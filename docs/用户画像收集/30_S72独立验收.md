## 实测中的语义边界

- 普通字段新增默认 authenticated 与关系分享默认 private 属于不同合同；每对象本人分享独立保存版本。
- education 和 portfolio_link 的选择引用绑定稳定 attribute_id；所选记录 private、friends 不获准或已删除时返回 null，不改选另一项。既有 native binding 只可作为未设置前的初始主主页；显式 null 不回退。
- overview 是合法当前活动详情，实际有效好友能读取本人设为 friends 的普通字段；普通发现仍只取 authenticated。联系方式继续经独立入口读取，合法 event_contact_preference 不是联系方式字段。
- 非本人 overview / relations 同样要求发现开关及已确认公开昵称；private 或 draft 昵称即时撤销入口，旧 cursor 不能绕过。self 入口继续可以查看本人资料。
- 原生 Space 的 hideMembers 或想法作者的 members_visible 限制对象成员关系；本人分享不能覆盖对象级撤权。想法正式详情与聊天权限分别判断。
- Messenger 原生 title 不是想法正式元数据，消息正文不构成简介。活动、想法、会话和好友资格分别检查。

## 发现与修复

先期发现一处 P1 路由参数回归：P8 query 校验使用 Yii 合并后的 queryParams，会把命名路径参数判为未知客户端字段。已通知实现人改为解析原始 query string；8101 真实 HTTP 已确认正常概览/关系读取及 spaceId、ownerId 注入拒绝。

主执行人另发现原生当前活动访问器与想法事务的接合冲突；实现人使用独立读连接保留原事务防护。本独立 HTTP 已实际通过修复后的发布、绑定、读取和撤权流程；本页不将该发现归为本工作包发现。

独立测试的两处先期修订不计作产品缺陷：联系方式断言改为精确 contact_ 字段键以免误排合法 event_contact_preference；未确认昵称 fixture 改用 schema 的 draft 枚举，原错误 pending 值被数据库约束正确拒绝。修订后完整重跑通过。
