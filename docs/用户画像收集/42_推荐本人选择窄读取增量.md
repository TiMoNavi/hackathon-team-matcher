# 推荐本人选择的最小读取扩展

2026-11-12。用户已授权多个 agent 补齐推荐页本人选择权威、候选字段用途与公共合同后正式接线。本记录只说明该批次对 P1 的最小读取增量，不改写 S1–S7 的历史验收。总体实施见[推荐文档24](../推荐模块/24_候选分析用途适配与登录协同.md)。

## 交付接口

P1 版本更新为 **0.10.1**，`Module::getSelectedSelfProfileReader()` 返回 `SelectedSelfProfileReader`。它依赖 P1 既有 `ProfileAccessPolicy` 与 `DiscoveryProfileBatchReader`，不依赖推荐插件类型。

```php
read(int $actorId, int $spaceId, array $sourceKeys, array $attributeIds): array
options(int $actorId, int $spaceId, array $sourceKeys): array
```

- `read` 的 IDs 必须显式提供，包括 `[]`。空选择只校验/返回元数据，不发起 attribute 值 SELECT。非空选择在 SQL 就用 owner、scope、IDs、confirmed、authenticated 和用途 sourceKeys 缩小读取范围，不能先读全部值再在 PHP 里筛。
- `options` 是本人选择器的独立读取用途，只列获准、已确认、authenticated 的适用条目。它不保存选择，也不授予模型使用权限。
- 返回沿用 batch 包装：schema_version、policy_version、本人 identity_version 及 global/当前 Space 的 scopes/版本/最小 attributes。移除编辑/存储内部元数据；任一明确选择不可用或身份/权限变化时拒绝旧投影，不把缺失选项当作静默空值。
- 前后验证本人及 Space 访问。服务端“当前活动”由调用方推荐应用用例验证，不能把调用方传入任意 spaceId 当当前活动。

推荐适配器还限制十种经审核的分析用途，并验证字段目录/schema、版本和当前活动；P1 不解析推荐规则，不把画像可见性等同于任意用途授权。

## 修改边界

新增 `application/SelectedSelfProfileReader.php`。精确修改：

- `Module.php`：增加惰性 getter。
- `domain/DiscoveryProfileBatchRequest.php`：增加可选 attributeIds。`null` 保持旧批量读取语义；`[]` 表示明确不取任何值。
- `application/DiscoveryProfileBatchReader.php`：传递并验证精确 IDs 与返回边界。
- `adapters/persistence/SqlDiscoveryProfileBatchSource.php`：SQL 条件包含明确 IDs；空集合不读 attribute 值。
- `module.json`：0.10.0 → 0.10.1。

未改变 P1 表结构、字段定义、资料写入、确认流程、原始来源、AI worker 或 P8。本人选择保存在推荐自有表，仅引用/版本，不在 P1 存第二套授权记录。推荐 GET 不写库，明确 PUT 才保存，SQL/CAS 的跨 context 版本不得重置。
