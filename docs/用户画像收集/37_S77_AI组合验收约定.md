2026-11-12，已完成，结果见 [主报告](38_S77_AI组合验收报告.md) 和 [独立报告](39_S77独立验收.md)。本轮按用户授权使用子 agent 推进 S7.7。延续后端范围，验收资料导入、AI 提取、本人采纳、选项与自由回答、画像生成、逐条隐私、最终确认及恢复；实际结果记录于 38/39 报告。

## 验收目标

同一普通资料服务承接 rules 与 ai，两种路径使用相同字段、草稿、确认版本和展示范围。长期资料保留在全局，本次角色、目标、投入等归属于对应 Space。进度沿用 S7.6 的三个紧凑接口，查询只读取状态，成功结果仍由本人确认。

真实网关使用现有私有配置与用户已指定模型，只有主 agent 执行。只发送本轮编造资料，不读取或发送主预览真实资料。单个完整链路计划 extract/questions/compose 各一次；失败明确记录，确需恢复时逐次显式重试，每个任务最多一次请求，试验最多 6 次模型请求。保留实际耗时、供应商用量及未知计量，不更换超时或静默切规则。网关不可用时如实标明未完成的真实验收。

## 检查范围

- AI 候选只进入指定草稿，采纳前不公开；私有输入和待核对提示仅本人可见。
- 补问 3–8 题，稳定选项、最后的自由填写入口、跳过与逐题保存；保存退出后继续原批次。
- 综合生成可编辑草稿，保留手工修改，继承输入的更严格范围，必须经本人最终确认。
- 资料或权限变更、来源删除、Space 撤权、取消和晚到结果均重新验证；失效结果不覆盖当前数据。
- 与 rules 路径比较资料与权限不变量，不要求模型生成的自然语言与规则模板逐字相同。
- 关闭 P6 可读已保存任务并主动走 rules，普通资料与发现维持 0 次模型调用；切 Space 后专属偏好分别保存。
- 会话/任务进度能观察 queued/running/ready 和恢复原因；轮询不发模型请求，不产生假百分比。
