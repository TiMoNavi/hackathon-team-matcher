## 用作前端数据

使用现有登录会话，先 PUT /api/v1/me/current-event 选择 Space 3 或 4，再读取当前活动内的 overview 和 relations API。模拟人物数据库 ID 从 [安装结果](../sources/s72-main-examples_2026-11-12.json) 的 synthetic_people 映射取得。具体请求载荷、CSRF、版本和响应字段见 [接口约定](../28_S72资料概览与关系摘要约定.md)。

安装入口是 backend/deploy/profile_s72_examples.php。主预览安装要求指定目标、确认参数及私有备份校验；再次执行会保留已完成记录和后续展示/分享修改。原始 100 人数据在 [人物目录](s7-people_2026-11-12.md)；这份示例不替代 300–400 人性能测试。
