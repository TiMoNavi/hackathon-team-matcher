# S7.7 AI 组合验收报告

2026-11-12，S7.7 已完成。本轮继续用户画像后端专项，先以合成适配器验证资料、隐私、版本和恢复，再由主 agent 单独执行指定网关的虚构资料验证。分工与预算见 [S7.7 约定](37_S77_AI组合验收约定.md)。

## 本轮关注的流程

本人导入资料 → AI 提取候选与证据 → 本人采纳和确认 → AI 生成带选项及自由填写入口的补充问题 → 逐题保存 → AI 生成画像草稿 → 本人编辑、核对展示范围并确认。

P1 普通资料保持数据权威，P2 编排会话，P6 负责模型传输和结构化校验，P8 负责获准投影。rules 与 ai 使用同一套草稿、确认和权限接口；长期资料与 Space 偏好继续分开。

进度复用 S7.6 的会话/任务/来源接口。真实异步任务需要确认 queued/running/ready 的可观察性，模型成功后仍由本人完成资料确认。进度查询不会执行 worker 或启动模型。

## 真实网关验证

使用用户指定网关和模型 gemini-3.8-flash，生产 P6 完成一组虚构资料的真实链路。三种操作均首次成功，没有重试、超时或未知调用记录。任务、来源、草稿和本人确认经专用库的真实 HTTP/MySQL 完成。

| 操作 | 实际耗时 | 供应商报告 tokens | 处理结果 |
|---|---:|---:|---|
| extract | 31.166 秒 | 6,940 | 带证据的候选被本人采纳进原草稿，采纳前不公开 |
| questions | 24.983 秒 | 7,910 | 返回选项与最后的自由填写入口，保存选择/自由回答/跳过，并恢复原题目位置 |
| compose | 13.931 秒 | 7,845 | 返回可编辑草稿，保留手工 private 简介，再经编辑和最终确认 |

[完整真实链路](sources/s77-live-http_2026-11-12.json)通过 **57 项检查、221 次 HTTP 请求**，其中流程请求 90 次、独立进度观察请求 131 次。三次模型请求累计报告 22,695 tokens，耗时合计 70.080 秒；这是模型处理时长相加，不是整套用户操作耗时。三个任务均实际观察到 queued → running → ready，percent 始终为 null，查询没有额外模型请求。

最终确认前仍处于可编辑状态；确认后获准用户能读取 authenticated 城市，private 简介不展示，联系方式不进入普通资料投影。重新登录恢复问题和本人手工草稿；进入下一 Space 保留全局资料并从空的 Space 偏好开始。

真实调用由主 agent 在严格选定 root 库、合成 owner 与 checkpoint job 上执行。生产默认模型配置仅由该 worker 使用；HTTP 验收服务器只有不可执行模型的能力占位。三个独立 worker 记录与观察记录保存在 sources/s77-live-*-worker / observe 文件，凭据和原始资料没有进入报告。

独立 agent 对七份真实导出完成 [34 项只读交叉复核](sources/s77_audit_live_review_2026-11-12.json)，核对 worker、HTTP、观察样本、用量与无正文容器；复核没有增加模型调用。

这是一组虚构资料的实际验证，可以证明本次链路和进度可用，不能据此推定任意简历的抽取质量或网关长期稳定性。实际超时、取消与晚到结果由合成场景验证，真实链路没有人为制造额外付费失败请求。

## 本轮变更

没有发现需要修改 P1/P2/P6 生产逻辑的缺陷，模块版本保持 P1 0.10.0、P2 0.4.0、P6 0.1.0；没有新增数据库迁移。新增内容是组合验收、真实链路工具及证据。

交叉复核修复了验收工具的三类问题：原地账本写入中断可能丢失预算；前置拒绝可能覆盖 checkpoint；失败/取消后的未知与晚到计量可能漏记或误报。现使用独立锁与原子账本替换，空坏账本拒绝执行，前置拒绝不修改 checkpoint，报告合并 worker 与 HTTP 计量。修复后离线复验通过，真实链路仍只执行计划中的三次调用。
