## 隔离与方法

仅连接主 agent 明确通知 ready 的 `humhub_profile_s77_test_audit_a8c52e14` 与 `http://127.0.0.1:8107`。独立 bootstrap 在加载应用配置前验证精确库名，router 验证 loopback、Host 和端口；空目标、主预览、root 克隆及相似后缀四个负例均在连接前被拒绝。

测试创建 8 个 `s77_audit_` 合成人物，使用克隆内既有两个 Space。普通 HTTP 使用原生登录会话、CSRF、服务路由和 MySQL 持久层；worker 是独立 CLI 进程，延迟传输时由另一个真实 HTTP 请求观察或变更状态。没有读取 `.local/`、凭据、真实用户原文，没有调用外网或真实模型。生产实现、前端、参考工程、原生 core/Messenger 和冻结原稿不在本包写入范围。

P6 注入的是 `StructuredProfileAiEngine`，不是绕过 P6 的直接 engine 成功返回。合成 transport 消费真实 `PromptBuilder` 生成的输入，返回模型协议 envelope；P6 负责响应解码、字段/证据/范围校验与计量。额外返回一次含非法 `confirmed` 字段的响应，实际 P6 必须将任务置为 `AI_OUTPUT_INVALID`，且保留已发生的合成用量。

| 来源与撤权 | 当前成功提取后删除来源，任务 revoked 且 result=null，失效私有输入/结果清空；传输中撤销 Space 成员后，晚到结果不能使用，原会话访问 403 |
| P6 生命周期 | 专用库禁用 P6 后，已存 queued 任务、来源和会话进度可读且指纹/调用数不变，能力 available=false；用户显式 rules 能生成问题。重新启用后同一 queued ID 保留并成功执行 |
| 普通读取 | 完成会话、本人资料与能力读取不改所检持久表，不增加 transport/reader；合法当前活动下发现、普通详情、独立联系方式读取均为 0 次新增模型调用，不含私有标记；不同当前活动发现被 409 拒绝 |
