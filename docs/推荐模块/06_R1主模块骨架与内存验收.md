> 2026-11-11。用户在 R0 验收后授权继续推进。本阶段对应 task.md R1.1–R1.6，现已完成。不接真实候选数据库，不开放 HTTP API，不启用预览环境中的推荐模块。

## 1. 模块接入

主模块采用原生 HumHub 装配方式，三个入口文件为 [module.json](../../backend/protected/modules/matcher-recommendation/module.json)、[config.php](../../backend/protected/modules/matcher-recommendation/config.php)、[Module.php](../../backend/protected/modules/matcher-recommendation/Module.php)。继承原生 Module，使用原生 ModuleManager 登记命名空间，不修改核心加载器。

与 example-basic 的关系是复用其展示的原生插件入口和装配约定，推荐业务仍由本模块的领域、用例和适配接口承担。固定版本及参考范围见 [03 开源调研](03_GitHub参考后端调研.md)；未引入新的插件框架。

- 模块 ID 为 matcher-recommendation，版本0.1.0，HumHub最低1.19.4；manifest只声明P1最低0.2.0，不依赖rest、AI包、模型SDK或向量服务。
- config仅返回静态装配数据，events和urlManagerRules暂为空；不在加载时读取当前用户、P1资料、settings值或网络。
- Module通过setDiscoveryService显式接受应用用例；hasDiscoveryService只说明是否装配，不表示用户已授权。未注入时getDiscoveryService明确报依赖未配置，不默认构造测试fake或读取原生Profile兜底。
- 没有自动加载P1实例。P1自身初始化会挂身份和原生编辑适配，不应为了推荐模块加载检查而触发这些行为。
- AI包尚未创建；即使以后安装，也由可选提供者边界接入，主模块不import其具体类。

P1本轮仍为0.2.0/FieldCatalog v2，公开签名与R0一致；单用户读取新增锁后权限复核，但没有据此把它视为批量发现接口。真实当前Space、推荐用途批量投影和关系适配仍留R3。

## 2. 纯用例与内存适配

R1把结构化查询流程装配成DiscoverPeople：可信当前Space→有界召回→最小投影→当前关系/屏蔽→注入的规则评估→确定性结果。领域和应用只引用纯PHP合同，数据库、框架和模型留在外层。普通发现保留好友及pending状态，不要求AI专用的终态申请历史。

本阶段只支持person目标和直接提供的结构化条件。selectedSelfAttributeIds与currentIdeaId尚无获准输入解析端口，传入时明确拒绝，不能忽略选择后返回看似成功的结果；后续接入本人字段和项目上下文时，须同时绑定授权与输入版本。

规则评估依赖RuleEvaluator端口。R1使用显式注入的合成测试实现证明流程可运行；R2才实现完整的类型化规则、权重与策略发布，不能把测试评估器默认注册为生产算法。

召回路排名随候选传给RuleEvaluator，保留R2计算RRF所需信息，R1不提前实现正式公式。发布前重新读取选中投影和关系；撤权、屏蔽或真实版本/内容变化会减少结果，不自动补人。关联映射的键顺序会先规范化再比较，列表顺序保留，避免仅因字段返回顺序不同而误删。

策略、批次和时钟通过窄端口提供，测试使用内存数据与可控时间。测试资料与画像字段都是虚构的，源字段通过显式用途绑定，既不要求about/title等原生列，也不要求用户填写全部可选项。

## 3. 原生装配测试的实际范围

[原生注册测试](../../backend/protected/modules/matcher-recommendation/tests/integration/module.php)加载Yii自身入口，构造独立内存Application，使用真实ModuleDependencyService、ModuleManager与推荐Module。安装状态和数据库访问用测试哨兵隔离。

先验证未启用模块保持静默，再调用ModuleManager的内存markAsEnabled并登记、实例化模块。没有调用持久化enable、迁移、应用run、生产配置或P1的数据库测试bootstrap。这个测试证明原生装配可用，不证明本机数据库依赖/模块启用或真实HTTP可用。

测试配置显式禁用Yii扩展自动bootstrap与日志输出。PHP使用-n跳过本地配置，并关闭URL流及常用网络连接函数；不读取.local、.env或运行时凭据。

```sh
backend/.runtime/php-mysql/bin/php -n -d allow_url_fopen=0 -d disable_functions=fsockopen,pfsockopen,stream_socket_client,curl_exec,curl_multi_exec backend/protected/modules/matcher-recommendation/tests/integration/module.php
```

## 4. 文件范围与后续条件

共享文件只追加protected/modules/.gitignore中的四行精确例外：主模块和未来AI模块各自目录及内容。已有P1白名单完整保留，没有修改根.gitignore、composer文件/锁、原版配置或其他插件。白名单不等于创建AI包，也没有执行git提交。

原版核心、vendor、原生字段快照及冻结稿按阶段开始/结束散列比较。P1并行开发的变化不回滚，也不将它们计作本推荐任务的实现。

下一阶段R2补齐实际规则；R3/R4接真实业务适配和API。普通发现的分页与真实投影撤权能力不能用本阶段的内存批次测试代替。
