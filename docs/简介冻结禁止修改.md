线下活动的技术向社交推荐平台

主要面向黑客松，开发者，企业等交流活动 

简介：

产品首先具备完整的社交软件基础：注册登录、发现、广场发布、好友申请、建立群聊、文字聊天、个人资料编辑、隐私可见性管理。

修改点：

1.增加“活动” 这个层级，活动自动生成唯一邀请码，由邀请码加入，在切换到对应“活动” 模式后，广场，和推荐，会分出独立的，属于这个活动的模块，不会被计入世界模块，推荐和发现功能的可见性，只会在这次活动，但是只有推荐和发现，在活动界面，会仅限此次活动，聊天系统是正常的

2.“群组” 更名为“想法” ，待定一个群组锚定一个发起人的想法，项目，每个群聊会自带项目agent，一个人可以有发起多个想法群组，也可以没有

3.关于个人资料编辑，首先正常的编辑模式依然需要生效

但是在用户首次登录的时候，需要引入1.ai爬github 2.ai理解简历并结构化拆分 3. ai爬取外部网页（若用户给出） 4. ai对话让用户选  4种方式，在4阶段ai引导用户通过对话的方式填写，和描绘用户画像，避免用户在填信息阶段流失，并且注意让ai自动判断6

4.推荐、发现功能

类似牵手，tinder，探探，推荐筛选一批，然后卡片滑动模式浏览，可以感兴趣的加好友

左边卡片，右边项目

5.添加好友逻辑  直接滑动添加  1.加对方个人 2.邀请对方谈谈想法（进群）

6.信息可见性  首先信息分为2个维度 是否必填  是否公开展示

公开展示的信息就是用户在加好友前，在推荐页和广场能看到的
